# 에르마 · 헤일로 UI 리소스

**2026-10-26 게임 연결:** HUD와 UI-18~23 메뉴를 포함한 연결 내용·조작·배포·검증 범위는 [게임 연결 기록](INTEGRATION_ko.md)을 확인하세요. 아래 내용은 리소스 제작 기준과 제작 당시 검토 기록입니다.

《침묵하는 관문》의 SF 개척지에 맞춘 **ERMA / FIELD INTERFACE v1.1** UI 제작 묶음입니다. 체력·탄약·수배·스캐너·속도는 **상태 패널을 없애고 게이지·아이콘·핵심 수치의 HUD**로 구성했습니다. 대화·기록·지도·메뉴에만 필요한 패널을 사용합니다.

## 납품 내용

- **UI-01~17:** 체력/전투/조준, 목표, 미니맵/지도, 상호작용, 대화/기록, 스캐너/구조/동료, 수배/악명, 바이크/교통, 알림, 의료 이송, 일시정지용 리소스와 상태 명세.
- **UI-18~23:** 타이틀, 옵션, 보유·성장 요약, 보급 교환, 확인 창, 맥락별 도움말의 후속 연결용 디자인.
- **아이콘 53종:** 개별 SVG 원본과 48×48 투명 PNG. 기호의 기준 크기는 24px이며 PNG를 2배로 출력했습니다.
- **HUD 아이콘 20종:** 검정 외곽선이 포함된 SVG와 64×64 투명 PNG. 밝은 배경에서도 아이콘의 윤곽을 보호합니다.
- **공통 부품 39종:** 기존 메뉴 부품에 HUD용 체력/재장전/열도 게이지, 탄창 칸, 스캔 링, 독립 조준 팔 11종을 추가했습니다. 게이지·원호는 런타임 도형으로 구현할 수 있으며, 부품은 모양 기준과 대체 스프라이트입니다.
- **합성 검토 화면 34개:** 편집 가능한 SVG와 1280×800 PNG. HUD 부품 구성·탐험·저체력 예시, 상태 갤러리, 상호작용, 알림, 긴 한글·큰 수치 검토를 포함합니다.
- **아이콘 아틀라스:** `Export/Atlases/icons.png`와 픽셀 좌표·정규화 UV를 담은 `icons.json`. 셀마다 4px 투명 여유가 있습니다.
- **연결 계약:** `Source/ui_state_catalog.json`의 23개 UI 상태/데이터/노출 조건과 `Source/layouts.json`의 14개 배치 템플릿. HUD 처리 항목은 `presentation= hud_primitives`, `dedicated_status_panel=false`로 구분합니다.

이 묶음은 **리소스 제작 납품**입니다. 게임 소스·실행 파일·Runtime 캐시는 변경하지 않았습니다. 메뉴 입력, 실제 옵션 적용, 지도 데이터, 동적 줄바꿈, 게임 데이터 바인딩은 해당 연결 작업에서 구현해야 합니다. 화면의 문구·가격·피해·손실·진행률은 디자인 검토용 예시이며 정식 스토리 원문이나 고정 게임 수치가 아닙니다.

## 파일 사용

| 위치 | 용도 |
|---|---|
| `Source/Icons` | 텍스트 없는 벡터 아이콘 원본 |
| `Source/HUDIcons`, `Export/HUDIcons` | HUD 전용 검정 외곽선 포함 기호 |
| `Source/Components` | 독립 배경·테두리·게이지·상태 벡터 |
| `Source/Screens` | 레이아웃·타이포그래피 편집용 합성 화면 |
| `Export/Icons`, `Export/Components` | 게임에서 합성할 투명 PNG |
| `Export/Atlases` | 아이콘 아틀라스와 UV 좌표 |
| `Preview` | 대표 화면 PNG와 전체 화면 모음 |
| `Validation` | 실제 글자 폭·겹침·글리프·알파·대비 검사와 해상도/투명도별 캡처 |

게임에는 완성 화면 PNG를 통째로 붙이지 않고 **개별 부품과 게임이 그리는 텍스트**를 조합합니다. 완성 화면에는 약식 배경과 샘플 문구가 들어 있으므로 검토용으로 사용합니다. 배경은 밝은 도시·복잡한 건축·어두운 광산을 대신한 도형이며 실제 게임 캡처가 아닙니다.

SVG는 표준 벡터 편집기에서 수정할 수 있습니다. 맑은 고딕이 없는 환경에서는 화면의 글꼴이 달라질 수 있습니다. 글꼴 파일은 배포하지 않으며 Windows 시스템 글꼴을 사용합니다.

## 배치·타이포그래피

- 기준 캔버스 1280×800, 외곽 안전 여백 32px. 1920×1080과 2560×1440에서는 비율을 유지해 확대하고 남는 부분을 여백으로 둡니다. 그리기와 마우스 좌표에 같은 변환/역변환을 적용해야 합니다.
- 대화 본문 20px/행간 32px, 일반 보조 문구 최소 14px. 체력 현재값 28px, 탄약 현재값 38px, 속도 44px로 강조합니다. 체력 게이지는 12px로 두껍게 제작했습니다. 조작 행은 높이 46px, 행 간격 58px를 기본으로 둡니다. 작은 영문 아이콘 이름은 제작 갤러리의 식별자입니다.
- 긴 대화는 실제 글리프 폭으로 줄바꿈한 뒤 본문 3줄 단위로 페이지를 분리합니다. 필수 대사와 선택지를 말줄임으로 버리지 않습니다. 긴 화자명·선택지는 줄바꿈 후 영역을 확장하거나 다음 페이지로 넘깁니다.
- 체력은 좌하단, 탄약/탑승 시 속도는 우하단, 현재 목표는 좌상단, 미니맵은 우상단에 둡니다. 무전 중에도 체력·탄약의 위치를 유지하도록 대화 패널을 y=700 전에 끝냅니다. 안전 대화에서는 전투 HUD를 감춥니다. 정상 상태의 무기명·조작 장문·전체 악명 수치를 상시 펼치지 않습니다.
- 대화가 열려 있을 때 일반 알림은 대기시킵니다. 긴급 경고만 상단의 비어 있는 슬롯을 사용합니다. 정보가 많은 화면은 상세 메뉴로 분리합니다.

## 투명도·이미지 합성

- 패널 배경, 테두리, 내용은 독립적으로 합성합니다. 권장 기본 불투명도는 **배경 94%, 테두리 100%, 내용 100%**입니다. 투명도는 `1 − 불투명도`입니다.
- 배경 없는 HUD는 밝은 내용과 검정 외곽선으로 윤곽을 보호합니다. HUD 내용의 불투명도는 게이지·아이콘·문자·외곽선을 그룹으로 묶어 한 번만 적용합니다. 큰 상태 패널로 대체하지 않습니다.
- 제작 기준의 지원 제안 범위는 **배경 80~100%, 테두리 80~100%, 내용 85~100%**입니다. 밝은 배경에서 보조 문구의 대비를 확보하도록 하한을 정했습니다. 실제 옵션 범위·값 저장은 게임 연결 단계에서 적용합니다.
- 미리보기는 극단 조건 검토를 위해 배경 불투명도 30%까지 노출합니다. **80% 미만은 권장 범위 밖**이며 모든 배경에서 가독성을 보장하지 않습니다. 낮은 불투명도를 게임 옵션으로 허용할 경우 글자 뒤의 별도 명암 보호판 등 추가 처리가 필요합니다.
- PNG는 sRGB, straight RGBA입니다. 기존 알파에 레이어 불투명도를 한 번 곱하고 `SRC_ALPHA / ONE_MINUS_SRC_ALPHA`로 합성합니다. premultiplied 렌더러는 색상도 변환해야 합니다.
- 흰색 아이콘은 게임에서 색상을 지정할 수 있습니다. 패널의 배경·테두리와 아이콘·문자를 하나의 텍스처에 합쳐 투명도 제어를 막지 않습니다.
- `nine_slice_ltrb`가 있는 부품은 모서리를 보존하는 9분할 확대를 사용합니다. 잠금/경고 기호가 포함된 고정 버튼 이미지는 가로로 늘리지 말고, 일반 버튼 배경과 독립 잠금/경고 아이콘을 조합합니다.
- 게이지 채움은 길이에 맞춰 **잘라서** 그립니다. 원형 미니맵은 `minimap_mask`와 동일한 원으로 모든 지형·표식·아이콘을 자릅니다. 원 밖 목적지는 별도 가장자리 화살표로 표현합니다.
- 조준의 팔 간격은 실제 탄퍼짐으로 조정합니다. ready/spread/recovering/blocked 이미지는 상태 참고와 고정 프레임용이며 동적 탄퍼짐은 팔을 분리해 이동시키거나 벡터 경로를 재사용합니다.

## 기능 맥락

- 지도의 북쪽은 오른쪽 위로 고정하고 플레이어/바이크 방향만 회전합니다. 자동 길찾기 경로선을 표시하지 않습니다.
- 광산의 미탐험 지형·정확한 구조 대상 위치를 공개하지 않습니다. 근사 신호의 삼각형과 사용자가 지정한 정확한 목적지 핀을 구분합니다.
- 예비 탄창은 무제한이라고 표시합니다. 바이크는 속도·부스트·후진만 표현하고 연료/배터리/부스트 에너지는 만들지 않습니다.
- 현재 추격은 별/열도, 도시 사이에 남는 상태는 악명으로 구분합니다. 악명이 저장 파일로 영구 보존된다고 표현하지 않습니다.
- 동료는 실제 합류 후 표시합니다. 광산의 반복 구조와 1장 운송대 고정 5명을 구분합니다.
- 의료 이송은 입력을 막고, 복귀 후 실제 적용된 손실과 기록 유지/대화 재개 안내를 표시합니다. 게임 오버/불러오기 기능은 없습니다.
- 일시정지의 R은 도시에서 다시 시작, 광산에서 광산 재시작, 1장에서 헤일로 귀환입니다. 새 게임/진행 초기화/종료 확인 창은 후속 연결용입니다.

## 디자인 근거

관련 상태는 같은 패널 안에 가까이 놓고, 같은 기능에는 같은 위치·기호·여백을 반복했습니다. 정보 위계와 관련 요소 묶기를 실제 화면의 탐색 시간을 줄이기 위한 배치 기준으로 사용했습니다.

색상은 형태와 문구로 보완했습니다. 선택 행은 좌측 강조선과 방향 기호, 비활성은 자물쇠, 위험은 경고 기호와 명시적 문구를 함께 사용합니다. [W3C의 색상 단독 의존 방지 설명](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)을 참고했습니다.

활성 정보 텍스트의 계산상 명암 대비 목표는 **4.5:1 이상**입니다. [W3C 최소 대비 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)의 값을 게임 UI 검토 기준으로 참고했으며 웹 접근성 적합 인증을 주장하지 않습니다. 포인터 조작 행은 높이 46px로 제작했고, [W3C의 포인터 목표 크기 설명](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)을 참고했습니다. 실제 클릭 영역과 키보드 포커스 동작은 게임 연결 시 맞춰야 합니다.

## 검증·재제작

`Validation/browser_report.json`은 브라우저에서 렌더한 텍스트의 실제 폭, 캔버스 이탈, 텍스트끼리의 겹침, 투명도 제어와 미리보기 오류를 기록합니다. 글꼴 글리프 누락·알파·배경 합성 대비·요구사항 대응은 `Validation/asset_report.json`, 최종 파일 해시는 `Validation/sha256.json`에서 확인합니다. 검토 결과와 한계는 [검수 기록](Validation/REVIEW_ko.md)에 있습니다.

재제작 순서:

```text
python Resource/UI/Tools/build_ui.py
python Resource/UI/Tools/build_contract.py
node Resource/UI/Tools/render_ui.cjs
python Resource/UI/Tools/verify_ui.py
```

렌더 도구에는 Playwright와 Sharp, 설치된 Edge가 필요합니다. 번들 모듈 위치는 `UI_NODE_MODULES`, 브라우저 경로는 `UI_BROWSER_PATH`로 바꿀 수 있습니다. 렌더 도구는 창 없는 별도 검토 브라우저를 사용합니다. 게임 실행·코드 빌드·실제 메뉴 조작을 수행하지 않습니다.

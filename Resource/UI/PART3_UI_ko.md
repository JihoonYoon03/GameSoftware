| UI-30 9분할 | 기존 패널·버튼과 새 배지·카드·칩의 투명 RGB 경계를 보정했습니다. 원본 알파와 보이는 픽셀은 보존하고 아틀라스에서만 인접 RGB를 최대 2px 확장합니다. [크기별 예시](Preview/20261127/114_panel_seam_review.png) · [아틀라스 검사](Validation/20261127/atlas_report.json) |

배지의 기본 배경 알파는 88%이며 테두리와 사용자 조절값을 분리합니다. 분리형 키캡에는 고정 E를 벡터 윤곽으로 그렸습니다. 게임에 키 재지정이 추가될 경우 기존 일반 키캡과 런타임 글꼴을 사용합니다. 진열창의 제목과 가격 영역도 별도로 합성합니다.

9분할은 기본 12px이고 파츠 칩에는 8px을 사용합니다. 잘림 좌표를 인접 조각에서 공유하고, 배경 또는 테두리 알파는 해당 레이어에 한 번 적용합니다. 아틀라스의 4px 패딩은 알파 0을 유지합니다. 기존 단일 아이콘 아틀라스의 역할을 통합 아틀라스에서 처리합니다.

통합 아틀라스는 2,048×2,048 RGBA8, 약 0.28 MB PNG 및 16 MiB GPU 기본 레벨입니다. 행성·성계용 9개 그림은 기존 `Export/Textures/ColonyV4` 출력물을 재사용하며, 가장 큰 비압축 기본 레벨은 32 MiB입니다. [지도 텍스처별 크기와 해시](Source/part3_map_art.json)

새 배치의 게임 내 입력·시각 검증은 별도입니다. 기존 UI 화면과 새 화면을 같은 브라우저에서 검사했고, 9분할 텍셀 검사는 아틀라스 데이터를 대상으로 했습니다. [검수 기록](Validation/REVIEW_ko.md)

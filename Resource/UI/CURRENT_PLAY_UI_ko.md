# 최신 플레이 UI 제작 · 2026-11-23

최신 게임의 도보 기동, 주 무장, 공용차·비행, 수배 대응, 월드 이동과 저장을 검토해 전용 디자인이 빠진 27개 상황을 제작했습니다. 기존 70개 화면과 공통 UI 부품을 함께 제공합니다. [최신 화면 비교](Preview/20261123/contact_sheet.png) · [상황·불투명도 미리보기](preview.html) · [좌표·데이터 명세](Source/current_play_ui.json)

| 도보와 스태미너 | 체력 바로 아래에 220×6 게이지와 회피 최소량 표시를 둡니다. 값과 기준은 `PlayerMobility::Stamina`, `MaxStamina`, `DodgeCost`에서 가져옵니다. 회피 중이거나 부족할 때 오른쪽에 한 줄을 띄웁니다. 탑승·안전 대화·입력이 잠긴 화면에서는 감춥니다. [부족 상태](Preview/20261123/72_stamina_low.png) |
| 펄스 카빈 | 기존 Q 휠 위쪽에 주 무장을 표시합니다. 해금 전에는 빈 슬롯으로 보여 주고 이름·그림을 숨깁니다. 탄창과 재장전은 현재 무기의 값을 사용하고, 전술 집중은 활성 상태에서만 한 줄로 표시합니다. [무기 선택](Preview/20261123/77_carbine_wheel.png) · [재장전](Preview/20261123/75_carbine_reload.png) |
| 공용차·비행체 | 우하단 속도 위치를 공유합니다. 실제 내구도, 지면 기준 고도, 후진·순항·착륙 상태와 지금 가능한 조작만 표시합니다. 기체 파괴 때는 공통 경고를 사용하고 의료 이송이 시작되면 기존 전환을 우선합니다. [순항](Preview/20261123/80_flight_cruise.png) · [착륙](Preview/20261123/81_flight_landing.png) · [조작](Preview/20261123/97_flight_controls.png) |

| 행성 지도와 중계환 | 지도를 왼쪽, 등록 목록과 이동 조작을 오른쪽에 둡니다. 청록 중계환과 금색 목적지 핀은 형태도 다르게 표시합니다. 선택·제한·목적지 준비를 구분하고, 실제 준비 중에는 X 또는 Esc 취소를 안내합니다. 실패나 제한 사유의 원문은 줄바꿈하거나 페이지를 나눕니다. 지도 지형·지역명·거리는 배치 확인용 예시입니다. [목적지 선택](Preview/20261123/87_relay_ready.png) · [준비 중](Preview/20261123/89_relay_prep.png) |

패널 배경과 테두리, 콘텐츠는 각각 조절할 수 있습니다. HUD 글자와 기호에는 검정 외곽선을 적용하고 새 일반 기호 8종과 HUD 외곽선 변형 6종에는 텍스트를 굽지 않았습니다. HSV 색 차이만으로 정보를 전달하지 않도록 슬롯의 상태, 지도 기호, 경고 문구를 함께 사용합니다.

네이티브 연동 시에는 실제 정보 우선순위와 입력에 같은 좌표를 적용합니다. 체력·탄약·스태미너·차량 정보는 상시 카드 없이 표시합니다. 일부 대표 화면의 위치·수치·색상은 리소스 검토용입니다. 작업 범위는 SVG·PNG, 공용 아틀라스 및 구현 명세입니다. 새 리소스의 실제 화면 배치와 입력 결합은 게임 통합 단계에 있습니다. [검수 기록](Validation/REVIEW_ko.md)

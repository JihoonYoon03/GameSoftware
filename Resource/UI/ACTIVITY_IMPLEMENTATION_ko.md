## 정보 위계와 배치

이야기 임무/지역 의뢰를 상단 탭으로 묶고, 왼쪽은 활동 목록과 조작, 오른쪽은 선택한 기록과 다음 행동으로 나눴습니다. 근접성·공통 영역·정렬 일관성을 적용해 서로 다른 기능을 구분했습니다. 작은 버튼에 큰 잠금/화살표 기호를 넣지 않고 명령 문구를 한 줄로 유지합니다.

1280×800 기준 기록 창은 `(64,40,1152,720)`입니다. 이야기 4행은 472×86, 간격 94px, 지역 목록은 한 페이지 최대 3행·472×112·간격 122px입니다. 제목 아래에 상태와 참여·추적 버튼을 둡니다. 참여 버튼 116×32, 추적/지도 버튼 134×32, 간격 12px입니다. 긴 지역명은 18px 두 줄로 배치하고 상세 제목은 24px로 줄바꿈합니다. 본문은 20px, 보조 문구는 16/18px입니다.

목록 페이지 제어와 본문 페이지 제어는 각 열의 아래에 독립적으로 둡니다. 목록 제어 영역 `(392,629,166,34)`, 본문 제어 `(944,629,212,34)`, 페이지 문구 기준선 Y=651입니다. 한 페이지뿐이면 이전/다음을 비활성화합니다. 긴 본문은 실제 글꼴 폭·남은 높이로 전부 페이지 처리하고 목록 페이지를 바꾸지 않습니다. 닫기는 우하단 Y=697입니다. 좌표의 권위 원본은 `Source/activity_design_contract.json`입니다.

## 상태·동작 계약

| 상태/행동 | 표시와 조건 |
|---|---|
| 진행 중 | 재생 기호 + `진행 중`; 참여 조작은 `진행 보류`, 추적 조작은 별도 |
| 보류 | 일시정지 기호 + `보류`; `재개`만 가능, 추적 비활성 |
| 미수락 | 추가 기호 + `미수락`; 자격이 있으면 `수락`, 추적 비활성 |
| 선행 조사 필요 | 문서/잠금 기호 + 전체 조건; 수락/추적 비활성 |
| 완료 | 확인 기호 + `완료`; 재수락/중복 보상/추적 없음 |
| 추적 중 | 청록 마름모·중앙 표적 + `추적 중`; 참여 상태와 별개 |
| 선택한 기록 | 오른쪽 열의 열람 항목. 선택한 기록과 추적 대상이 다를 수 있음 |
| 지역 측정 | 현재 행성에서 수락한 기존 측정 의뢰만 표시 |
| 지역 제출 대기 | 측정 기록 유지, 센서 대신 현장 접수 단말을 다음 목표로 표시 |
| 정산 보류 | 제출 단계 유지. 보상 전액 지급 성공 전까지 완료 표시 금지 |

기존 이야기 네 개는 `전망대의 목소리`, `광산 구조 신호`, `빛나는 개척지`, `남겨 둔 불빛`입니다. 지역 종류는 `중계 잡음 측정`, `전력 분기 진단`, `환경 센서 점검`을 재사용합니다. 긴 지역명과 실패 원인은 검토용 예시이며 신규 콘텐츠·실제 오류로 등록하지 않습니다. 실제 명칭·단계·자격·원인·목표 좌표는 게임 조회 결과를 사용해야 합니다.

목록 이름은 추적 선택, 지도 버튼은 해당 목표 중심 지도 열기입니다. 이 화면에서 원격 수락·기록 제출·보상 지급을 하지 않습니다. 참여/추적 변경은 별도 입력 처리에서 수행하고, 그리기·페이지 전환·`Current` 조회는 읽기 전용입니다. `ActivityJournal`의 `Current`, `CommunityEntries`, `TrackMission`, `TrackCommunity`, `CaptureTracking`, `RestoreTracking`을 연결 시작점으로 삼습니다.

## 저장·복원·완료

8형식 저장의 이야기 선택, 지역 행성/지역 식별자, 이전 이야기 추적을 사용합니다. 복원 후 J의 탭과 목록 페이지는 선택된 활동에서 계산합니다. 창 열림·포인터·눌림은 저장하지 않습니다. 유효한 복원은 일반 추적 표시를 재사용하며 별도 확인 팝업을 띄우지 않습니다.

완료/중단/없는 의뢰/다른 행성 참조는 추적만 정리하고 기존 진행·재화는 보존합니다. 1~7형식 저장은 기존 진행에서 활성 이야기/자유 탐사 목표를 선택합니다. 복원만으로 임무를 수락·재개하거나 보상을 지급하지 않습니다.

기존 지역 보상은 100크레딧입니다. 한도를 넘으면 전액 정산을 보류하고 측정 기록·추적·기존 잔액을 유지합니다. 일부 지급이나 보상 폐기 후 완료 처리를 하지 않습니다. 실제 지급 후에만 완료/목록 제거/대체 목표 갱신을 수행합니다. 정산 완료 의뢰는 다시 지급하지 않습니다.

정산 안내는 다음 원문 전체를 보존합니다.

> 의뢰 정산 보류 / 크레딧 소지 한도로 보상을 받을 수 없습니다. 측정 기록은 유지되며, 여유가 생기면 이 단말에서 다시 제출할 수 있습니다.

현재 검토 글꼴에서는 제목과 본문 4줄로 한 화면에 들어갑니다. 더 긴 실제 원인은 원문 줄바꿈 후 4줄씩 페이지 처리합니다. 알림은 페이지별로 충분한 표시 시간을 주고 UI 시간으로 진행합니다. 대화 중 일반 알림은 대기시키며 긴급 알림은 비어 있는 슬롯으로 옮깁니다. 정상 이동·복원에 새 승인 팝업을 추가하지 않습니다.

이야기 보고 강조는 `StoryMissionProgress::CanComplete` 공통 판정을 사용합니다. 필요한 사실을 얻어도 명시적 보고/최종 대화 전에는 보고·기록 대조 목표를 유지합니다. 마지막 대화에서 완료를 거절하면 재개할 수 있고 성공한 경우에만 완료/해금을 표시합니다. `completion_ready`를 상시 HUD나 완료 표시로 사용하지 않습니다.

## HUD·지도와 합성

체력·탄약·재장전·스캐너·수배·속도는 기존 게이지·아이콘·수치 HUD를 유지합니다. 별도 상시 상태 카드를 만들지 않습니다. 목표 제목/다음 행동은 좌상단에 두고 긴 부가 문맥은 최대 두 줄씩 페이지 처리합니다. 실제 합성 규칙은 `HUD_IMPLEMENTATION_ko.md`를 따릅니다.

추적 표식은 청록 표적 마름모, 직접 지정 목적지는 금색 핀입니다. 전체 지도에서 다른 수락한 의뢰는 작은 보조 마름모로 남깁니다. 목표 변경·지도 열기로 지정 목적지를 덮어쓰지 않고 자동 경로선은 그리지 않습니다. 지상 목표를 광산에서 추적하면 알려진 출구를 안내하며 미탐험 지형/표식을 공개하지 않습니다. 북쪽은 오른쪽 위 고정, 배우 방향만 회전합니다.

아이콘은 동적 문구와 분리된 SVG/투명 PNG입니다. 새 HUD 표적에는 검정 외곽선을 사용합니다. 패널 배경·테두리·내용의 불투명도는 독립 적용하며 기존 알파에 한 번만 곱합니다. 권장 범위는 배경/테두리 80~100%, 내용 85~100%입니다. 창 크기는 비율 유지 배율과 여백을 적용하고 입력 좌표도 역변환해야 합니다.

## 검토 자료와 통합 후 확인

`Preview/20261109`의 50~70번 화면, `Source/activity_review_states.json`, `Source/text_flows.json`과 `Validation/REVIEW_ko.md`를 제공합니다. 독립 HTML 미리보기는 상태 선택·알림 페이지·투명도 검토용이며 게임 동작을 시뮬레이션하는 클라이언트가 아닙니다. SVG 안의 게임 버튼은 디자인 예시입니다.

게임 연결 후에는 여러 이야기 참여 중 추적 전환, 지역 0/1/4개 이상 목록, 측정→제출→정산 보류→저장/복원→정상 지급→재방문, 최종 대화 거절/재개, 행성 왕복·의료 이송·잘못된 참조를 확인해야 합니다. 실제 장면의 UI 하한 알파와 지원 해상도에서 입력·글자·안개·목적지 보존을 검증해야 합니다. 제작 검토 통과를 해당 게임 동작 검증으로 표기하지 않습니다.

## 후속 게임 연결 — 2026-11-09

`ActivityJournalUi`로 두 열/상태·강조·독립 목록/본문 페이지를 연결했다. 이야기 행은 열람 선택, 별도 버튼은 HUD 추적이며 지역 이름 선택은 기존 의뢰 추적을 유지한다. 본문은 실제 글꼴 폭과 높이로 전부 보존하고 제목 순환으로 본문 페이지가 바뀌지 않게 했다. 최신 게임의 저장 9형식/1~8 읽기를 유지하며 열람 ID와 본문 페이지는 저장하지 않는다. 제작 예시 문구를 새 사건이나 실제 오류로 등록하지 않았다. [게임 통합 기록](INTEGRATION_ko.md#후속-게임-통합--2026-11-09)을 따르며 네이티브/시각 검증은 사용자 실행 대기다.

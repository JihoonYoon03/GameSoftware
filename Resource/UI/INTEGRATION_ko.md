# UI 게임 연결 기록

최신 갱신은 문서 끝의 **후속 게임 통합 — 2026-10-28**이다. 아래 2026-10-26 내용과 디자인 v1.2 제작 기록은 기존 연결 이력으로 보존한다.

적용일: 2026-10-26  
리소스: ERMA / FIELD INTERFACE v1.1 (`ui_manifest.json`)

## 적용 범위

제작된 완성 화면을 배경에 붙이는 방식이 아니라 `Export/Icons`, `Export/HUDIcons`, `Export/Components`의 **112개 개별 부품**과 실제 게임 텍스트·수치·도형을 조합했다. 원본 SVG, 제작 미리보기와 모델 Runtime 팩은 변경하지 않았다.

- **HUD:** 체력, 탄창 칸/재장전, 실제 탄퍼짐 조준점, 현재 목표, 원형 약도/목적지, 스캐너 충전·진행/근사 신호, 합류 동료/구조, 수배 별·열도, 바이크 속도·부스트·후진, 교통/상호작용/짧은 알림을 연결했다. 기존 대형 상태 카드는 제거했다.
- **대화·기록·지도:** 화자/전달 방식·순차 본문·선택 버튼, 조사 기록/이력과 페이지 이동, 45도 고정 지도/탐험 안개/사용자 목적지를 유지하며 새 부품으로 표시한다. 필수 대사는 실제 Malgun Gothic 20px 폭으로 3줄씩 나누고 조작은 E/Enter·숫자 또는 클릭으로 연결한다. 보통 알림은 대화가 끝날 때까지 같은 슬롯에 보관한다.
- **메뉴:** 타이틀, 일시정지, 옵션, 보유/성장 요약, 1장 운송대 보급 교환, 진행 초기화/귀환/종료 확인, 조작 도움말을 연결했다. 의료 이송 후에는 실제 손실과 기록 유지/대화 재개 방법을 보여 주는 복귀 화면을 연다.
- **현재 데이터만 사용:** 예비 탄창은 무제한, 바이크 연료/부스트 에너지는 없다. 미탐험 광산이나 미래의 조사 사실을 공개하지 않는다. 저장/불러오기, 장비 장착·상품 상점·후속 장 사건을 UI 때문에 추가하지 않았다.

메뉴/선택지 입력은 같은 입력으로 사격·상호작용·중복 구매가 일어나지 않게 소비한다. 기존 1장 현장 출발 선택도 유지한다. 도시의 새 게임과 광산 재시작은 확인을 거치고, 1장 귀환은 조사 기록을 보존한다.

## 투명도·그리기

- 기본 불투명도는 배경 94%, 테두리 100%, 내용 100%다. 옵션 범위는 배경/테두리 80~100%, 내용 85~100%이며 1% 단위로 조절한다.
- 내용 불투명도는 제출되는 UI 정점의 알파에 한 번만 적용한다. 배경/테두리는 각각의 불투명도로 따로 합성하며, 에셋 고유 알파는 보존한다.
- 설정은 **현재 실행 세션**에 보관하고 새 게임에서도 유지한다. 프로그램 재실행 후 복원하는 설정 파일/게임 저장은 이번에 추가하지 않았다.
- 1280×800 기준 캔버스와 기존 비율 유지 확대/여백을 사용한다. 게임 조명·광산 암막·월드 픽셀 후처리 뒤에 UI를 합성한다. 메뉴와 대화 패널은 모서리를 보존하는 9분할로 확대하고, 게이지는 실제 값에 맞춰 잘라 그린다.
- HUD 글자는 캐시된 검정 외곽선과 함께 그리며 새 PNG는 straight RGBA로 읽어 기존 알파 합성에 연결한다. PNG 부품은 시작 시 하나의 GPU 아틀라스로 묶고 GL 컨텍스트 생존 중 해제한다.
- 안전 대화에서는 전투 HUD를 숨긴다. 위험 중 무전은 기존 하단 체력·탄약 위치를 유지하고 대화 패널은 y=700 전에 끝난다. 교전 중 기록 화면에는 시간이 흐른다는 경고를 표시한다.

## 검증 기록

- 별도 코어/검사 프로그램의 컴파일·링크와 아래 회귀 검사를 통과했다. 사용자 게임 실행 파일은 교체하지 않았다.
- GameplayTests: 메뉴 열기/닫기·파괴적 행동 취소, 1920×1080 여백을 고려한 포인터 역변환, 불투명도 하한과 새 게임 유지, 거래 불가/정상 거래·평판 가격·E 유지 중 중복 구매 방지, 기존 대화·의료 복귀·퀘스트 진행을 함께 검사한다.
- CivicTests, MapHudTests, RoadPlanTests, SceneGraphTests, ConsoleOutputTests로 치안/물리·지도·도로·그래프·출력의 회귀를 확인한다. 지도 GPU 검사도 새 미니맵 중심/반경에 맞춰 방향 고정·원 밖 누출·목적지 화살표를 검사한다.
- RenderingTests: 타이틀/일시정지/옵션/보유/도움말/확인/거래/의료, 도시 수배·저체력·재장전, 바이크 후진/부스트, 광산 스캔/무전·픽셀 월드, 최소 불투명도, 대화/기록/지도와 긴 한글을 실제 숨겨진 WGL 표면에 출력한다. 1920×1080·2560×1440의 대화 화면도 캡처한다.
- 결과 위치: `x64/RevisionChecks/ui-integration-renders`, `x64/RevisionChecks/ui-integration-render.log`. 최종 컴파일·검사 결과는 통합 개발 문서에 기록했다. RTX 5080·1280×800의 14개 장면 검사에서 도시 p95 2.44ms, 수배 5단계 p95 2.83ms였다. 다른 하드웨어/실제 창 표시를 포함한 프레임을 보장하는 수치는 아니다.
- 일반 실행 진입점의 별도 컴파일과 `CopyGameUiResources` 단독 실행으로 배포 대상도 검사한다. 사용자 빌드에서의 장시간 수동 플레이와 다양한 화면/하드웨어 확인은 남아 있다.

이 문서는 실제 연결 상태를 기록하며, 제작 당시의 `README_ko.md`·`HUD_IMPLEMENTATION_ko.md`·Validation 자료는 리소스 제작 기준/당시 검토 기록으로 함께 보존한다.

## 2026-10-28 디자인 v1.2 및 내용 보존 수정

### 제작 납품

UI-24 원형 무기 선택, 맨손/권총 비조준/우클릭 조준/재장전 HUD, 해금 안내와 최신 Q/G 조작, UI-25 스테이지 목록을 추가했다. 기존 타이틀·일시정지·옵션·보유·기록·이력·도움말·긴 대화도 재설계했다. 현재 납품은 일반 아이콘 58종 + HUD 아이콘 24종 + 공통 부품 45종 = **개별 PNG 127개**, 기존 방식의 아이콘 아틀라스 1장이다. 합성 검토 화면은 48개다. 최신 파일 경로는 `ui_manifest.json`을 기준으로 한다.

### 실제 게임 코드 반영

- 알림은 두 줄 뒤에 `…`를 붙여 나머지를 버리던 코드를 제거했다. `Hud::TextPages`가 실제 글꼴 폭으로 줄바꿈한 모든 줄을 페이지에 보존한다. 긴 알림은 4줄씩·페이지마다 6초, 짧은 알림은 4초이며 페이지 위치와 자동 다음 안내를 표시한다.
- 목표도 두 줄 이후를 버리지 않고 전체 줄을 2줄 단위로 보존한다. 5초 간격의 페이지 표시와 J 전체 목표 안내를 제공한다. 원문에 원래 들어 있는 이야기 문장부호 `…`는 보존한다.
- 타이틀을 왼쪽 제목/행동 목록으로 재배치했다. 일시정지의 일곱 행동과 하단 안내 간격을 정리했다. 스테이지 목록은 6개 행과 시작 조건 설명을 나누고, 초기화·이전 필수 스토리 완료 처리를 선택 전에 표시한다. 조작 안내의 폭을 늘렸다.
- 무기 선택의 맨손·빈 슬롯을 새 아이콘으로 교체했다. 현재 장착 체크와 가리키는 후보를 분리하고 미보유 보조 슬롯에 권총을 노출하지 않는다. 원형 선택 중 일반 HUD·알림을 숨겨 겹침을 없앴다. Q 유지/해제·Esc 취소, 커서 제한과 기존 무장 규칙은 유지했다.
- 새 제작 화면의 모든 좌표가 게임 코드에 그대로 재연결된 것은 아니다. 옵션·기록 등의 일부 화면은 새 디자인 리소스/명세를 납품하고 기존 게임 연결을 유지한다. 모델·애니메이션·게임 규칙을 UI 작업 때문에 추가하지 않았다.

### 검증과 실행 파일

- 별도 `x64/UIRevision20261028`에서 전체 코어와 GameplayTests/RenderingTests를 새로 컴파일·링크했다. 사용자의 Debug/Release 게임 실행 파일은 교체하지 않았다.
- GameplayTests가 통과했다. 새 검사는 긴 알림·목표를 페이지별로 합쳐 마지막 문장과 원문 문장부호까지 보존되는지, 각 줄의 실제 폭·페이지 줄 수와 전체 알림 시간이 맞는지 확인한다. 기존 무기 선택·장착·해금·스테이지·조준·메뉴·입력 회귀도 함께 실행했다.
- RenderingTests의 `--dialogue-only` 검사가 실제 RTX 5080 WGL 표면에서 통과했다. 기존 대화·기록·메뉴·의료와 함께 무기 미보유/권총 보유/최소 불투명도, 스테이지 해금 설명, 긴 알림의 모든 페이지를 렌더했다. 최종 UI 캡처 27개는 `Validation/Game_20261028_Final`에 있다.
- 제작 브라우저 검사는 48개 화면의 글자 이탈/겹침 0, 글리프 누락 0, 원문 64건의 글자 보존을 확인했다. `preview.html`의 다음 내용·이전 내용·PageUp 이동도 통과했다.
- 빌드/실행 로그: `x64/ui-revision-20261028-build.log`, `x64/ui-revision-20261028-gameplay.log`, `x64/ui-revision-20261028-render.log`. 제작 검사: `Validation/browser_report.json`, `asset_report.json`, `preview_navigation.json`.

실제 사용자 창에서의 장시간 플레이와 모든 제작 레이아웃의 재연결은 이번 검수 완료 범위에 포함하지 않는다. 기존 UI 투명도 옵션과 상태 공개 조건은 유지했다.

## 후속 게임 통합 — 2026-10-28

사용자의 UI·애니메이션 적용 요청에 따라 앞의 제작 변경을 유지하면서 남은 연결을 진행했다.

- 새 개별 이미지 127개를 자동 디렉터리 로더로 읽는다. 맨손/비조준 포인터와 HUD 맨손·우클릭 아이콘을 연결했다. 원형 무기 선택 구획 PNG는 제작 계약대로 런타임 도형의 디자인 참고이며, 기존 선택·보유·장착 구분을 유지한다.
- 옵션을 왼쪽 투명도 슬라이더/오른쪽 렌더 설정으로 구성하고 실제 버튼 범위에 맞춰 드래그 좌표를 수정했다. 보유·성장 정보, 두 열 조작 안내, 조사 기록/대사 이력을 넓은 공통 패널에 배치했다. 기록은 실제 글꼴 폭 714px, 페이지당 15줄로 전체 내용을 보존한다. 도움말 하단도 폭에 맞춰 줄바꿈한다.
- 광산 입구에서 권총을 처음 인계받으면 해금 알림을 표시한다. 기존 광산 진입 안내도 함께 보존한다. 테스트 스테이지의 선행 완료·맨손 기본 장착, Q 선택 및 새 무기를 만들지 않는 규칙은 유지한다.

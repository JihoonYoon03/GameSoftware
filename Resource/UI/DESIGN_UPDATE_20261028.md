## 디자인

- SF 현장 단말의 짙은 청회색, 밝은 중성색 본문, 절제된 민트 강조를 공통으로 사용했다. 패널 모서리·가는 테두리·정렬선과 여백을 통일하고, HUD의 지나치게 두꺼운 외곽선은 3px stroke로 정리했다.
- 체력·탄약·속도·수배·스캐너는 기존의 작은 HUD 구성으로 유지했다. 새 조준 충전 게이지나 애니메이션 가중치 자원을 추가하지 않았다.
- 타이틀은 제목과 행동을 분리하고, 일시정지는 7개 행동을 충분한 간격으로 배치했다. 옵션은 UI 투명도와 그래픽 항목을, 성장 요약은 항목명과 수치를, 기록은 목록·확인한 사실·다음 행동을 분리했다.
- 무기 선택은 세 구획과 가운데 후보 정보로 구성했다. 현재 장착은 체크, 가리킴은 명확한 구획 외곽선과 배경, 비활성은 빈 슬롯 기호와 상태 문구로 구분한다. 미보유 보조 슬롯에는 권총을 미리 노출하지 않는다. Q 유지/해제·Esc 취소를 표시하며 클릭 확인 버튼은 만들지 않았다.
- 스테이지 목록은 왼쪽의 6개 진입 지점과 오른쪽의 시작 조건 설명으로 나눴다. 초기화·이전 필수 스토리 완료 처리는 선택 전에 읽을 수 있고, 추가 확인 팝업은 없다.
- 현재 조작은 Q 무기 선택, G 회복, 우클릭 홀드 조준이다. 맨손에는 탄약을 숨기고 비조준 포인터·조준점·사격 불가·메뉴 포인터를 구분한다.

## 말줄임표로 내용을 잃던 문제

1. 실제 게임의 `Hud::DrawNoticePanel`은 두 줄만 그린 뒤 `…`를 붙였다. 모든 줄을 네 줄 단위 페이지로 보관하도록 바꿨다. 긴 알림은 페이지마다 6초, 짧은 알림은 기존 4초를 사용하며 현재/전체 페이지와 자동 다음 안내를 표시한다.
2. 목표도 두 줄 이후를 버리던 제한을 제거했다. 긴 목표는 모든 줄을 두 줄 단위 페이지로 유지하고 5초 간격으로 표시하며, 페이지 번호와 J 전체 목표 안내를 제공한다.
3. 제작용 긴 대화는 원문과 긴 선택지 전체를 유지한 페이지 예시로 만들었다. `preview.html`의 이전/다음 내용 버튼, PageUp/PageDown으로 나머지를 확인할 수 있다. 중요한 대화는 게임에서 기존처럼 사용자 입력으로 넘긴다.
4. 실제 맑은 고딕 폭을 측정해 단어 경계에서 줄바꿈한다. 단어 자체가 길면 글자 단위로 나누며, 폰트 측정 차이의 여유도 확보했다. 작은 글자로 압축하거나 필수 문장을 삭제하지 않는다.
5. `Source/text_flows.json`에 64개 원문·전체 줄을 보관해 글자 누락을 검사한다. 이야기 원문에 원래 있는 `…`는 연기·호흡을 표현하는 문장부호이므로 제거하지 않는다.

## 납품·실제 연결 구분

- 아이콘 58종, 외곽선 포함 HUD 아이콘 24종, 공통 부품 45종, 합성 화면 48개. PNG 개별 부품은 127개이며 텍스트·수치·키 이름을 분리했다.
- UI-01~25, 상태 155개, 배치 템플릿 17개. 무기 선택은 5개 대표 상황, 무장/조준은 4개 HUD 상황으로 검토한다. P2 개발용 애니메이션 표시·신규 게임 자원·후속 장 메뉴는 추가하지 않았다.
- 이전 PNG는 비교 기록이다. 최신 PNG는 날짜·리비전이 붙으며 `ui_manifest.json`과 대응표가 최신 파일을 가리킨다.
- 게임 코드에는 내용 보존, 무기 선택의 아이콘·현재 장착 표시·선택 중 기존 HUD 숨김, 타이틀·일시정지·스테이지 배치와 도움말 폭을 반영했다. 나머지 제작 화면의 모든 좌표를 실제 게임에 그대로 재연결한 것은 아니다.
- 별도 GameplayTests와 WGL RenderingTests를 사용했다. 실제 게임 캡처는 `Validation/Game_20261028_Final`에 남겼다. 사용자 게임 실행 파일·모델 Runtime 팩은 교체하지 않았다.

자동 검수: 제작 화면 48개의 글꼴·폭·겹침, 원문 64건의 글자 보존, 무기 미보유 정보 비공개, 투명 PNG·대비를 검사했다. 게임 규칙 검사는 페이지를 합쳐 마지막 문장과 원문 문장부호까지 복원되는지 확인한다. 렌더 검사는 긴 알림 전 페이지, 무기 선택의 미보유/보유/최소 불투명도, 스테이지 진입 설명을 포함한다. 상세 수치는 `Validation/asset_report.json`, `Validation/browser_report.json`, `INTEGRATION_ko.md`를 따른다.

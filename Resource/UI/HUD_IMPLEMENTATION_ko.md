# HUD 구현 명세 — 가시성·시야 확보 개선

버전 1.2 / 2026-10-28 / 기준 캔버스 1280×800

사용자 지시: **체력·탄약처럼 HUD에서 표현할 수 있는 정보는 별도 창이나 상태 카드로 화면을 가리지 않는다. 게이지·아이콘·핵심 수치로 단순화하고, 해당 구현 사항을 별도로 명시한다.**

이 문서는 HUD 제작·연결 기준이다. 2026-10-28에는 리소스 재설계와 함께 실제 게임의 알림/목표 내용 보존, 무기 선택, 타이틀·일시정지·스테이지 배치, 도움말 표시를 수정했다. 사용자 실행 파일은 교체하지 않았다. 기존 게임 연결과 이번 변경의 정확한 범위는 `INTEGRATION_ko.md`를 따른다.

## 2. 체력 HUD

- 위치: 좌하단. 십자 기호의 내용 좌표 `(32,736)`, 현재 수치 기준선 `(66,735)`, 최대 수치 기준선 `(118,734)`.
- 게이지 채움: `(66,748,220,12)`. 어두운 바탕과 외곽선은 사방 2px 확장한다. 이전의 6px 게이지보다 두껍게 제작했다.
- 데이터: `SimpleGame/Level.h`의 `PlayerStats.health / maxHealth`. 현재 도시/광산/1장이 사용하는 실제 플레이어를 참조하고, UI용 체력을 별도로 복사해 유지하지 않는다.
- 값: `ratio = clamp(health / max(1, maxHealth), 0, 1)`. 채움 길이는 `220 × ratio`로 잘라 그린다. 최대치가 0인 잘못된 입력은 나눗셈으로 전파하지 않는다.
- 현재 수치 28px, 최대 수치 18px. 최대치나 현재치의 자릿수가 커지면 실제 글자 폭으로 다음 수치 위치를 정한다. 샘플의 고정 좌표 때문에 숫자를 겹쳐 그리지 않는다.
- 체력이 최대의 **25% 이하**면 위험 색상, 짧아진 게이지, `위험 · G 회복`을 함께 표시한다. 경고 기준선 `(32,690)`으로 체력 수치와 간격을 확보한다. 화면 전체의 붉은 덮개나 강한 점멸은 추가하지 않는다.
- 회복/피격은 실제 반영량만 짧은 알림으로 표시한다. 게이지의 과도한 점멸이나 체력 수치의 위치 이동은 하지 않는다.
- 체력 0 이후에는 기존 의료 이송 흐름이 HUD를 대체한다. 별도 게임 오버를 추가하지 않는다.

## 3. 탄약·재장전 HUD

- 위치: 우하단. 권총 기호 `(1040,723)`, 현재 탄수 오른쪽 기준선 `(1182,746)`, 최대 탄수 오른쪽 기준선 `(1248,745)`.
- 현재 탄수 38px, 최대 탄수 22px. 현재 탄수는 크게, 보조 정보는 작게 두어 시선을 한곳에서 읽는다.
- 데이터: `Firearm::GetRounds()`, `GetMagazineSize()`, `IsReloading()`, `GetReloadProgress()`와 `GetSpread()`. 현재 `Pistol`의 탄창은 12발이지만 수치는 반환값으로 채운다.
- 탄창 칸: 시작 `(1090,757)`, 각 칸 `9×10`, 간격을 포함한 이동 13px. 현재 탄수만 채운다. 빈 칸과 채운 칸의 명도·채움 형태가 달라야 한다.
- 일반 사격 상태에는 무기명·조작 설명을 계속 쓰지 않는다. 권총 아이콘, 잔탄, 탄창 칸으로 충분하다. 예비 탄창은 작은 무한 기호로 구분하고 도움말에 **예비 탄창 무제한**을 명시한다. 유한 예비 탄수는 만들지 않는다.
- 탄창이 비었으면 `00`과 `R 재장전`을 표시한다. 재장전 중에는 탄창 칸 자리를 `(1090,757,152,10)` 진행 게이지로 교체하고 `재장전`과 조준 불가 X를 표시한다. 별도 재장전 패널은 만들지 않는다.
- 진행률은 실제 게임 진행률이며 UI가 독립 타이머로 완료를 추정하지 않는다. 재장전 종료 시 실제 탄수를 다시 읽고 칸 표시로 복귀한다.
- 무기 사용 불가, 바이크 탑승, 안전 대화, 전체 메뉴에서는 숨긴다. 탑승 중에는 같은 우하단 앵커를 속도 표시가 사용한다.

## 4. 나머지 HUD 구성

### 조준

2026-10-28 갱신: 아래 조준 팔은 권총을 장착하고 우클릭을 유지한 조준 상태에 사용한다. 맨손·비조준의 기본 포인터와 구분하며, 새 상태/제작 범위는 [요청서 7절](UI_REQUIREMENTS.md#7-추가-제작-요청--2026-10-28)을 따른다. Q는 원형 무기 선택, G는 회복 키트다.

`hud_reticle_arm`을 팔 4개로 따로 배치하고 `GetSpread()`의 증가/회복에 맞춰 중심에서의 간격을 바꾼다. 고정 이미지 4장을 임의 시간으로 번갈아 표시하지 않는다. 밝은 지형 위에서도 보이도록 밝은 기호와 어두운 외곽선을 함께 그린다. 메뉴 포커스 시에는 메뉴 커서로 교체하고 사격 입력을 차단한다.

### 스캐너

중심 `(976,656)`, 반지름 21px, 링 두께 4px. `MineState.scannerSeconds / scannerCooldown / scannerContacts` 등 실제 상태로 준비·진행·충전·발견·미발견을 구분한다. 진행 링은 위쪽에서 시계방향으로 `360 × progress`만큼 그린다. `hud_scan_arc`는 모양 참고용 60% 샘플이며, 가변 진행에는 런타임 원호 메시나 마스크를 사용한다. 준비 상태에는 F 기호만, 진행/충전에는 짧은 문구만 둔다.

구조 신호는 삼각형 방향 표시와 근사 거리 구간이다. 정확한 좌표 핀으로 바꾸거나 미탐험 지도를 공개하지 않는다.

### 수배·열도·악명

상단 중앙 별의 시작점 `(558,35)`, 간격 35px, 크기 25px. 실제 `CivicState.wanted`의 개수만 채운 별로, 나머지는 빈 별로 표시한다. 열도는 `CivicState.heat`를 기존 게임의 상한으로 정규화해 `(558,73,165,6)` 게이지에 그린다. 수배 0일 때 상시 `수배 없음` 카드로 공간을 점유하지 않는다.

`CivicState.infamy`는 현재 추격과 구분한다. 상세 수치와 거래 할증은 성장/보유 요약·보급 교환에서 확인하고, 상태가 바뀔 때만 짧게 알린다. 도시 이동 시 악명이 사라졌다고 표현하지 않으며 영구 저장 기능이 있다고도 표현하지 않는다.

### 속도·동료·목표·교통

- 속도: 우하단 44px 수치와 km/h. `abs(bikeSpeed) × metersPerWorldUnit × 3.6`을 사용한다. 후진은 음수 속도만 쓰지 말고 후진 기호/문구로 구분하며 낮은 속도는 소수 첫째 자리까지 허용한다. 부스트/후진 중에만 해당 기호를 표시한다. 연료·배터리·부스트 에너지 게이지는 없다.
- 동료: 실제 합류한 이름과 현재 상태만 표시한다. 중상·회복·철수처럼 변화가 있는 상태를 우선하고 정상 상태의 장문 설명은 숨긴다. 광산 반복 구조와 1장 운송대 고정 5명은 별개의 문구와 카운터다.
- 목표: 좌상단에 현재 행동 1줄과 필요 시 진행 1줄. 긴 제목은 실제 폭으로 두 줄까지 줄바꿈하되, 더 긴 상세는 J 기록으로 보낸다. 공개되지 않은 사실·미수락 의뢰를 노출하지 않는다.
- 교통: 실제 인접 횡단보도 상태를 사용하며 관련 구역을 떠나면 감춘다. 대기/횡단 가능은 기호와 문구로 함께 구분한다. 충돌 알림은 실제 적용 피해를 한 번만 보여 준다.
- 알림: 반복 이벤트는 같은 슬롯으로 합치고 일반 알림은 제안 기본 4초 뒤 사라진다. 중요한 대사는 자동으로 지우지 않는다. 획득/회복/보상은 작은 기호와 값으로 표시하며 별도의 큰 카드로 전투 시야를 가리지 않는다.

## 5. 가독성·투명도·레이어

- 핵심 수치 28/38/44px, 대화 본문 20px, 보조 문구 최소 14px. 아이콘 선 굵기는 24px 기준 2.1px로 보강했다.
- HUD 글자는 흰색 또는 밝은 상태 색상과 **4px 검정 stroke**를 함께 사용한다. SVG의 stroke는 글자 중심에 걸치므로 흰색 내부를 덮은 뒤 실제 바깥 테두리는 약 2px 남는다. 글꼴 렌더러가 stroke를 지원하지 않으면 주변 오프셋의 검정 마스크/거리장 외곽선으로 같은 효과를 낸다.
- HUD 아이콘은 `Export/HUDIcons`의 검정 외곽선 포함 64×64 PNG를 사용한다. 논리 크기 32px, 내부 기호는 24px, 여유 4px다. 내용 위치 `(x,y)`에 크기 `d`로 그릴 때 `s=d/24`, 스프라이트는 `(x−4s,y−4s,32s,32s)`에 둔다. 일반 메뉴 아이콘은 `Export/Icons`를 사용한다.
- 게이지·원호·조준 팔은 런타임 도형으로 충분하다. `Export/Components/hud_*`는 해당 도형의 디자인 기준과 대체 스프라이트이며 텍스트가 없다. **완성 화면 PNG나 체력/탄약 카드 이미지를 HUD에 통째로 붙이지 않는다.**
- HUD는 게임 조명·안개·저해상도 월드 후처리 뒤에 네이티브 화면 해상도로 합성한다. 월드 렌더를 반/1/4로 낮추더라도 HUD 글자를 함께 저해상도로 만들지 않는다.
- 내용 불투명도는 글자·아이콘·외곽선·게이지를 하나의 HUD 레이어로 묶어 한 번 곱한다. 자식마다 중복 적용하지 않는다. 패널 배경 투명도는 대화/메뉴/미니맵의 작은 보호 배경에만 별도로 적용한다.
- 기존 권장 기본값은 배경 94%, 내용 100%; 가독성 검토 범위는 배경 80~100%, 내용 85~100%다. 배경 없는 HUD의 대비는 글자/아이콘의 검정 외곽선으로 보호한다. 옵션의 더 낮은 불투명도는 추가 실장면 검토가 필요하다.
- 무전 대화는 아래쪽 `y=700` 전에 끝나고 체력/탄약은 기존 하단 위치에 남긴다. 대화 때문에 HUD를 화면 반대편으로 이동시키지 않는다. 안전 대화에서는 전투 HUD를 숨긴다.
- 기준 캔버스에서 비율 유지 확대·여백과 입력 역변환을 함께 사용한다. 실제 글자/UI 배율 옵션은 별도 구현 대상이다.

## 6. 참고와 적용 범위

- [Halo Infinite 공식 접근성 안내](https://support.halowaypoint.com/hc/en-us/articles/4408122295444-Accessibility-Features-in-Halo-Infinite): HUD·조준점·표식·이벤트 배경의 불투명도 제어를 분리하는 접근을 참고했다. 이 게임의 외형이나 에셋을 복제하지 않았다.
- [The Last of Us Part II 공식 접근성 안내](https://www.naughtydog.com/blog/the_last_of_us_part_ii_accessibility_features_detailed): HUD 크기·배경 명암·색상·점멸 제어와 조건부 시각 안내를 참고했다. 이번에는 크기·대비·조건부 표시를 디자인에 반영했다. 해당 게임의 기능 전체를 구현했다는 뜻은 아니다.

## 7. 통합 시 확인할 것

체력/탄창/원호는 실제 값으로 움직여야 하며 무기·조준·재장전의 상태가 서로 일치해야 한다. 밝은 도시·어두운 광산·복잡한 건축 뒤에서 모든 HUD를 확인하고, 큰 수치·긴 한글·0체력·0탄약·수배 0/5·중상·느린 후진·위험 중 무전과 의료 이송을 포함해 검토한다. 정상 상태에서 불필요한 설명이 계속 표시되지 않는지도 확인한다.

이번 검토에서는 제작용 브라우저 화면, 한글 글리프, 텍스트 폭/겹침, 알파 이미지, 전후 시야 점유 면적을 확인했다. **실제 게임의 입력·HUD 연결·옵션·렌더러는 아직 변경하거나 검증하지 않았다.**

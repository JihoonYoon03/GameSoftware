# 현재 게임에 필요한 UI 제작 요청

작성일: 2026-10-26  
대상: 《침묵하는 관문》의 도시·광산 프롤로그·1장 플레이 구간

현재 게임 기능을 정식 UI로 표현하기 위한 **필요 항목 목록**이다. 색상, 형태, 레이아웃, 연출과 제작 방식은 UI 제작 담당자가 결정한다. 이 문서는 UI 리소스 제작 요청이며 게임 코드나 새로운 게임 기능을 구현했다는 뜻이 아니다.

제작 공통 기준은 [UI 제작 기준](AGENTS.md), 게임 맥락은 [게임 개발 통합 문서](../../GAME_DOCUMENTATION.md)를 따른다. 저장소의 실제 리소스 경로는 `Resource/UI`다.

## 1. 먼저 제작할 UI — 현재 플레이에 직접 필요

아래 기능은 이미 기본적인 문자·도형 UI 또는 게임 규칙으로 존재한다. 기존 정보를 읽기 쉽고 일관된 UI로 교체하는 것이 우선이다. 모든 정보를 항상 펼쳐 놓을 필요는 없다.

| ID | 필요한 UI | 표시할 정보·필요한 상태 |
|---|---|---|
| UI-01 | 플레이어 상태 | 현재/최대 체력, 위험한 저체력 상태, 회복 결과. 레벨·경험치는 성장 확인 시 제공. 체력은 도시·광산·1장에서 같은 의미로 사용 |
| UI-02 | 무기·전투 상태 | 무기 이름/종류, 탄창의 현재/최대 탄수, 탄창 소진, 재장전 중/완료. 현재 권총의 예비 탄창은 무제한이므로 유한한 예비 탄약처럼 표시하지 않음 |
| UI-03 | 조준 표시 | 커서 위치와 조준 방향, 탄퍼짐의 증가/회복, 재장전 등 사격 불가 상태. 메뉴 조작 커서와 구분 |
| UI-04 | 목표 추적 | 현재 메인 목표와 다음 행동, 수락한 선택 의뢰의 진행/완료. 1장은 발전기·운송대·폐설비의 조사 상태와 헤일로 보고/대조 상태 |
| UI-05 | 원형 미니맵·목적지 안내 | 주변 도로·건물·구역의 약도, 플레이어 위치/방향, 현재 목표, 설정한 목적지와 거리, 원 밖 목적지의 방향, 지도 열기 안내 |
| UI-06 | 전체 지도 | 현재 지역 약도, 범례, 목표/주요 지점, 목적지 설정/해제, 닫기. 도시 주변·광산·1장 현장의 세 지도 맥락을 구분 |
| UI-07 | 근접 상호작용 안내·월드 표식 | 대상 이름, 가능한 행동, E 키 안내. 대화·조사·전력 조작·아이템 회수·구조·승하차·출입·보급 교환을 구분 |
| UI-08 | 대화·수신 기록·무전 | 화자, 전달 방식, 본문, 페이지 진행, E/Enter 다음, 숫자 선택과 확정. 현장 대화/무전/단말 메시지/수신 기록을 구분하고 선택/미선택/선택 불가 상태 제공 |
| UI-09 | 조사 기록·대사 이력 | J 조사 기록과 H 이력. 확인한 사실, 현재 할 일, 화자/전달 방식, 페이지 이동, 내용 없음. 중단된 대화가 있으면 안전한 곳에서 재개하는 안내 |
| UI-10 | 스캐너 | F 사용 가능, 스캔 진행, 충전 대기, 신호 발견, 감지된 신호 없음. 발견한 구조 신호의 근사 방향/거리와 화면 가장자리 삼각형 방향 표시 |
| UI-11 | 동료·구조 상태 | 실제 합류한 동료 이름/상태, 중상·치료/회복 중 상태, 구조 확인과 철수 중/안전 지점 도착. 광산의 반복 구조와 1장 운송대 5명 구조를 구분 |
| UI-12 | 수배·악명 | 수배 0~5단계, 수배 열도 게이지, 악명/평판, 평판에 따른 거래 할증. 현재 추격의 강도와 다른 도시에도 남는 악명을 구분 |
| UI-13 | 바이크 주행 | 탑승 상태, 실제 속도와 단위, 부스트 중, 후진, 정차/승하차 안내와 하차 불가 사유. 기본 주행과 부스트를 구분 |
| UI-14 | 교통 안내 | 횡단 가능한 보행 신호/대기 신호, 차량 충돌 위험과 피격 결과. 실제 도로 위 신호와 HUD 안내가 서로 모순되지 않음 |
| UI-15 | 공통 알림 | 획득·회복·보상·거래 결과·물자 부족·목표 갱신·지역 진입/귀환. 전투 중 반복 알림이 대화와 중요 목표를 덮지 않음 |
| UI-16 | 의료 이송·복귀 | 체력 0 이후 페이드/이송 안내, 도착 의료소, 실제 감소한 레벨·크레딧·부품, 조사 기록 유지 안내. 중단한 대화가 있으면 재개 방법 제공 |
| UI-17 | 일시정지 | 계속하기, 현재 상황에 맞는 다시 시작/광산 재시작/1장 헤일로 귀환, 종료와 조작 도움말. 상황별로 다른 R 키의 의미를 정확하게 설명 |

### 반드시 유지할 기능 맥락

- **지도:** 실시간 위성 화면이 아닌 약도다. 현재 약도는 시계방향 45도로 고정되고 북쪽은 오른쪽 위이며, 플레이어/바이크 방향만 바뀐다. 미니맵과 전체 지도의 방향을 일치시킨다.
- **광산 탐험:** 지나간 주변 구간만 지도에 남는다. 미탐험 지형·건물·목표·구조 대상의 정확한 위치를 UI가 미리 공개하지 않는다. 스캐너 감지는 지형 전체 공개와 별개다.
- **목적지:** 전체 지도에서 좌클릭 설정·우클릭 해제, M 또는 Esc로 닫는다. 미니맵 밖 목적지는 방향으로 안내한다. 현재 기능은 목적지 지정/방향 안내이며 자동 길찾기 경로선은 구현되어 있지 않다.
- **퀘스트 표식:** 맵에 상시 뜨는 퀘스트 표식은 현재 진행과 관련된 대상만 사용한다. 근접 상호작용 안내는 그때 실제 가능한 행동을 설명한다. 중상 NPC에게 정상 대화 표식을 띄우지 않는다.
- **대화:** 중요한 대사는 자동으로 사라지지 않는다. 긴 한글 본문과 선택지를 누락 없이 읽을 수 있어야 한다. 진행 키가 월드 상호작용이나 사격으로 동시에 전달되지 않아야 한다.
- **대화와 위험:** 안전 대화는 게임 진행을 잠그지만 교전/수배 중 무전·기록 열람은 전투 시간을 멈추지 않는다. 필수 선택을 확정할 수 없는 상황과 의료 이송 중 입력 불가를 설명할 수 있어야 한다.
- **조사 기록:** 아직 모르는 사실이나 미합류 동료를 미리 표시하지 않는다. N-0 관문과 N-0/17 외곽 설비 번호는 서로 다른 대상이다. 1장 결론은 마지막 대화를 읽어야 확정된다.
- **구조:** 광산에서 새로 생성되는 구조 대상은 반복 플레이 대상이다. 1장 운송대의 고정 5명이나 오래된 탐사선 신호와 혼동하지 않게 한다. 구조 의뢰와 무관한 처치 수를 필수 진행 목표처럼 표시하지 않는다.
- **바이크:** 현재 연료·배터리 소모·부스트 에너지 게이지는 없다. 속도/주행 상태만 표현하고 존재하지 않는 소모 자원을 추가하지 않는다.
- **패배:** 별도 게임 오버/최근 저장 불러오기 대신 의료 이송으로 복귀한다. 패널티는 실제 적용 결과를 표시하고, 원인을 불문한 공통 이송 흐름을 따른다.

## 2. 다음으로 필요한 화면 — UI 연결 작업이 추가로 필요

현재 플레이 정보를 활용할 수 있지만 완성된 메뉴로 구현되어 있지 않은 항목이다. 첫 제작 묶음 이후의 후보로 둔다.

| ID | 필요한 화면 | 필요한 항목·현재 제약 |
|---|---|---|
| UI-18 | 타이틀·시작 화면 | 새 게임, 옵션, 조작 안내, 종료. 영구 저장이 없으므로 이어하기/불러오기를 사용 가능한 기능처럼 제공하지 않음 |
| UI-19 | 옵션 | UI 투명도 조절은 필수 요구. 기존 카툰 명암 전환·기본/반/1/4 렌더 해상도·안티앨리어싱 상태의 설정 화면 후보. 읽기 편의를 위한 글자 크기/UI 배율도 검토하되 실제 지원은 별도 구현 필요 |
| UI-20 | 보유·성장 정보 요약 | 레벨, 경험치, 공격/방어, 크레딧, 거래 부품, 회복 키트 수량. 현재 데이터의 요약이며 아이템 격자·장비 슬롯·무기 교체 기능이 있는 것은 아님 |
| UI-21 | 보급 교환 | 현재 1장 운송대의 부품 → 회복 키트 교환 내용, 적용된 평판 할증 가격, 보유량, 교환 가능/부족/보유 상한, 결과. 현재는 E 즉시 교환이며 별도 거래 창/확인 버튼 연결은 추가 작업 |
| UI-22 | 중요한 행동의 확인 창 | 새 게임/진행 초기화/종료 등 현재 세션 진행을 잃을 수 있는 행동의 설명, 실행/취소. 저장되지 않는 상태임을 정확히 알림. 기존 1장 출발 확인과 공통 부품 재사용 가능 |
| UI-23 | 맥락별 조작 도움말 | 도보/전투/바이크/광산 스캔/지도/대화 조작. 현재 가능한 행동을 찾을 수 있게 하며 개발용 숫자 1·2 지역 진입 키를 정상 진행 메뉴처럼 노출하지 않음 |

옵션의 투명도는 이 폴더의 `AGENTS.md`에 이미 지정된 요구사항이다. 현재 게임에 해당 옵션 메뉴가 완성되었다는 뜻은 아니다. 세부 디자인과 조절 범위/기본값은 제작·통합 단계에서 정한다.

## 3. 지금은 본 제작 대상에서 제외할 UI

아래는 장기 확장 후보이며, 현재 기능에 맞춘 UI 제작과 혼동하지 않는다.

- 저장 슬롯·불러오기·자동 저장 알림: 영구 저장 기능이 먼저 필요하다.
- 정식 인벤토리·장비 장착·다중 무기 선택·아이템 상세 비교: 해당 게임 규칙이 먼저 필요하다.
- 일반 상점·매입/매각·상품 목록: 현재의 단순 보급 교환과 별개인 정식 상점 구현 후 연결한다.
- 2~4장·에필로그의 작전/대피/서사 선택 전용 화면: 실제 콘텐츠와 공개 조건이 확정된 뒤 연결한다.
- 스킬 트리·제작·수리 미니게임·멀티플레이 UI: 현재 게임에 없는 기능을 UI 때문에 추가하지 않는다.

## 4. 공통으로 필요한 UI 부품

정확한 외형이나 파일 형식을 지정하는 목록은 아니다. 위 화면들에서 반복 사용하는 기능 단위다.

- 패널·제목·본문·목록 행·구분 요소와 페이지 이동/닫기 부품.
- 버튼/선택 행의 기본·포커스/가리킴·눌림·선택·비활성·경고 상태.
- 체력·경험치·재장전·수배 열도·스캐너 충전처럼 값/진행률을 바꿀 수 있는 게이지.
- 키보드/마우스 입력 안내: E, Enter, 숫자 선택, J, H, M, F, R, Q, V, Esc, Space와 클릭/방향 조작. 각 장면에서 실제 지원하는 키만 안내한다.
- 체력/회복, 권총/탄창/재장전, 크레딧/부품, 퀘스트/조사/대화, 스캔/구조, 동료/중상, 의료소, 수배/평판, 바이크/부스트/후진을 식별할 아이콘.
- 지도용 플레이어·목적지·목표·구조 신호·주요 시설 기호, 범위 밖 방향 화살표와 범례용 기호. 정확한 위치와 근사 신호의 의미를 구분한다.

문자·수치·키 이름은 게임에서 바꿀 수 있게 분리한다. 패널 배경/테두리와 아이콘/본문은 투명도 조절이 가능하도록 구분한다. 색 하나만으로 선택·위험·상태를 구별하지 않는다.

## 5. 제작자가 확인할 대표 상황

완성도를 확인할 최소 사용 상황이며, 디자인 배치안은 아니다.

1. 집/밝은 도시: 체력·현재 목표·미니맵·근접 상호작용이 함께 있는 경우.
2. 도시 수배/교전: 체력 감소·탄창 소진/재장전·수배 상승·경고 알림이 겹치는 경우.
3. 바이크: 주행·부스트·아주 느린 후진, 목적지가 미니맵 밖에 있는 경우.
4. 어두운 광산: 탐험한 지도·스캐너 충전/진행·구조 신호 화살표·동료 중상 상태가 있는 경우.
5. 긴 대화/선택: 여러 페이지의 한글, 긴 화자명과 선택지, 별도 획득 알림이 있는 경우.
6. 조사 기록/이력: 내용 없음, 내용이 여러 페이지인 경우, 의료 이송으로 중단한 대화가 있는 경우.
7. 1장: 세 현장의 조사 순서가 다른 경우, 운송대 철수 중, 선택 의뢰와 보급 교환이 가능한 경우.
8. 의료 복귀/일시정지: 실제 손실 수치와 유지되는 기록, 지역에 따라 다른 재시작/귀환 안내.

현재 UI의 기준 캔버스는 1280×800이며 최종 게임 창에서는 배율/여백이 달라질 수 있다. 실제 사용할 글꼴·긴 문구·큰 수치와 조절 가능한 투명도에서 잘림·겹침·깨짐을 확인한다. 구체적인 지원 해상도와 디자인 규격은 제작 담당자가 정리한다.

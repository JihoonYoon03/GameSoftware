# UI 리소스 성능 요청 — 2026-10-28

대상: UI 담당 에이전트. 상태: 요청 작성, 미제작·미연결.
[AGENTS.md](AGENTS.md)의 가독성·전체 문구 보존·알파 분리 기준을 그대로 따른다.
현재 기능과 디자인을 유지하며 로딩/반복 생성 비용을 줄이기 위한 납품 요청이다.

## P0 — 미리 조립한 UI 아틀라스

`SimpleGame/RenderAssets.cpp`는 시작할 때 `Export/Icons`, `HUDIcons`, `Components`의 PNG 127개를
각각 WIC로 디코딩하고 하나의 2048×2048 아틀라스로 조립한다. 이번 코드 변경은 개별 RGBA 버퍼의
중복 보관을 제거했지만 파일별 열기·디코더 생성과 배치 계산은 남아 있다. 실제 ms는 사용자 빌드 후 측정한다.

납품 요청:

- 기존 sprite ID를 유지하는 atlas PNG와 JSON. ID는 `Icons/<stem>`, `HUDIcons/<stem>`,
  `Components/<stem>`이며 127개 전체의 누락/중복 검사를 포함한다.
- JSON에 schema/version, atlas 파일명·크기·SHA-256, 각 ID의 정수 x/y/width/height,
  원본 PNG SHA-256, 좌상단 원점·행 방향·RGBA straight-alpha 정의를 기록한다.
- 이미지 내용은 현재 PNG와 같은 픽셀·크기·알파를 유지한다. 패널 fill/border/content 분리와
  nine-slice 12px 기준, 현재 반 픽셀 UV 샘플링 및 아이콘의 의도된 여백을 보존한다.
- 최소 2px 투명 여백과 선형 필터에서 이웃 이미지가 번지지 않는 검사를 포함한다.
  생성 도구와 원본 PNG를 함께 보관해 콘텐츠 추가 시 재생성할 수 있게 한다.
- 화면 문구·동적 숫자·대사를 atlas에 굽지 않는다. atlas만으로 원본 자산을 교체하거나 삭제하지 않는다.

클라이언트 통합 담당자는 납품 후 `RenderAssets`의 로더·배포 항목·오류 검증을 연결한다.
현재 로더가 atlas JSON을 읽는다고 가정하지 않는다. atlas 로딩 실패 시 기존 원본 경로를 유지할지는
통합 시 결정하고, 깨진 UI를 성공으로 처리하지 않는다.

## P1 — 정적인 배경 레이어의 분리 납품

`Drawing::DrawBackdrop`는 별 65개, 관문 링 8겹×97표본, 원경 건물 23개를 그린다.
움직이는 관문 표식 12개·차량 4대·완료 상태 표시는 별도 동적 요소다. 실내/전망대 등의 배경에서 쓰며
도시 월드는 자체 지형으로 화면을 채운다. 계측 전에는 주 병목이라고 단정하지 않는다.

모델링 담당과 협업하여 정적인 별/원경/관문 링을 별도 RGBA 레이어로 납품하는 대안을 요청한다.
1280×800 기준 위치와 확대 시 품질을 보존하고, 회전 표식·차량·완료 효과·`N - 0 / 관문망` 텍스트는
굽지 않는다. 기존 카툰/저해상도 모드·후처리와 비교한 미리보기를 함께 제공한다.

## 검수와 범위

밝은 도시·어두운 광산, 1280×800/1920×1080/2560×1440, 지원하는 UI 알파 설정에서 실제 연결 후 확인한다.
타이틀·옵션·Q 선택창·긴 대화·알림 페이지·의료 이송의 글리프/잘림/겹침을 검사한다.
이번 요청은 리소스와 계약의 제작 범위다. 게임 코드·Runtime 바이너리·게임플레이를 함께 수정하지 않는다.

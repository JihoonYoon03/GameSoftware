# 모델링·애니메이션 성능 리소스 요청 — 2026-10-28

대상: 모델링·애니메이션 담당 에이전트. 상태: 요청 작성, 미제작·미연결.
[AGENTS.md](AGENTS.md)의 원본 디테일 보존·원래 파트당 최대 200삼각형·한도 우회 분할 금지 원칙을 따른다.
이미 납품된 클립/모델을 다시 만들기 위한 요청이 아니다. 측정 전 임의 폴리곤 감축을 하지 않는다.

## P0 — 런타임 도로 가공을 오프라인 납품으로 옮길 수 있는 계약

`SimpleGame/TransitLayout.cpp`의 `Fit`, `Paint`, `Assembly`, `Deform`, `JunctionArt`는 원본의
정점 복사·법선 변환·표면 추출·조립·교차로 변형을 CPU에서 수행하여 `RegisterStatic`으로 등록한다.
이미 정적 캐시가 적용되어 매 프레임 재제작하는 경로는 아니지만 시작 준비·정적 메모리의 후보이다.

- 기존 RoadPlan 라이브러리/asset_id를 보존한 채, 렌더용 윗면 페인트와 도로 본체/companion 조립 구성을
  명시한 내보내기 메타데이터를 제공한다. 원래 파트의 삼각형 예산을 우회하는 새 분할 GLB는 만들지 않는다.
- 페인트의 매립된 밑면과 실제 표시 윗면, 별도 보도, 지지 구조, 신호/정지선용 예약 구역을 구분한다.
  현 클라이언트는 페인트 윗면에 +0.006 월드 높이를 적용한다. 납품에 이를 미리 적용할지 원점 그대로
  둘지는 메타데이터에 명확히 기록하여 이중 오프셋을 방지한다.
- 접속 포트·실측 크기·법선·UV·재질, 지상/고가 level, 램프 경사·높이, 회전 경로·보행 여유를 보존한다.
  렌더 bounds와 충돌/접속 envelope를 분리하여 가려진 면 정리가 길·충돌을 바꾸지 않게 한다.
- 길이/교차각의 모든 조합을 별도 아트 파일로 폭증시키지 않는다. 현재 도시 고정 배치의 사전 변환은
  클라이언트의 오프라인 pack 도구가 담당하고, 디자이너는 원본과 재현 가능한 조립 계약을 제공한다.
- 확인할 기존 계약: `Documentation/road_plan_modules.json`, `ROAD_PLAN_ko.md`, `ROAD_MODULE_REQUEST.md`.

실제 교체는 클라이언트 담당자가 통행·신호·충돌 지문과 GPU 이미지를 비교한 뒤 수행한다.
기존 런타임 도로 생성 경로를 납품 전에 제거하지 않는다.

## P1 — 정적 배경과 반복 광원

`Drawing::DrawBackdrop`의 원경 건물 23개와 8겹 관문 링은 UI 담당과 협업하여 정적 배경 레이어로
대체할 수 있는지 검토한다. 동적 차량 4대·회전 표식·스토리 완료 표시를 정적 그림에 굽지 않는다.
현재 카메라의 45도 쿼터뷰·가림·기존 색/실루엣을 유지한 전후 비교가 필요하다.

`RenderAssets.cpp`의 재질 4종(64×64), 흰 셀, 방사형 glow는 현재 작은 CPU 생성 자원이다.
이번 리팩토링에서 불필요한 GPU 왕복을 제거했으므로 우선순위가 낮다. 이 경로가 실측에서 유의미하면
동일한 타일링/그라데이션/알파를 가진 PNG와 padded atlas를 납품한다. 예술적 재디자인은 별도 요청으로 취급한다.
동적으로 변하는 물/화염/스캐너/배기 셰이더를 무조건 큰 애니메이션 텍스처로 교체하지 않는다.

## 애니메이션 납품 계약

- 현재 23본·부모 순서·바인드·스킨·총구·발 접지·기존 전체 클립을 유지한다. 후진/옆걸음/권총 운반/재장전은
  이미 존재하므로 성능 리팩토링을 이유로 중복 제작하지 않는다.
- 새 모션은 클립명, duration, loop 여부, 기본 이동/상체/전신 구분, 참조할 블렌드 표본·마스크를 명시한다.
  런타임 이동·yaw·피격 판정은 게임이 소유하며 클립 root motion으로 바꾸지 않는다.
- 같은 리그·바인드·애니메이션을 쓰는 체형/의복/헤어는 공유 뱅크로 묶일 수 있게 식별 계약을 유지한다.
  미사용 클립을 원본에서 삭제하지 않는다. 클라이언트는 실제 연결된 그래프의 로컬 본 표본만 시작 때 준비한다.
- 향후 오프라인 로컬 TRS 표본 납품을 채택하면 이름/부모/바인드/표본 시간/쿼터니언 규약과 역변환 비교를 제공한다.
  현재 v3 바이너리 변경과 pack 도구 수정은 클라이언트 담당 영역이며 이번 요청만으로 바꾸지 않는다.

리소스 원본·내보내기·검증 자료는 Resource 안에 보관하고, 게임 코드/Runtime 캐시를 모델링 작업에서 수정하지 않는다.

## CQ-01E 후속 — 도시/지대별 실측 건물 메시 제작 요청 (2026-11-02)

사용자 확정 사항: **기존 건물을 늘이거나 줄여 다른 크기/용도로 사용하는 것은 현재 테스트 단계에서만 허용한다. 정식 콘텐츠에서는 용도·규모에 맞는 새 건물 메시가 필요하다.** 이번 요청은 제작 대기이며 기존 리소스 교체나 폴리곤 감축을 바로 수행하라는 지시가 아니다.

- 시내의 소규모 주거·상점/정비소·의료소, 소도시의 물류/대중교통·시장, 대도시의 복합 주거/행정·상업, 항성계 수도의 관문 행정/대형 공공 건물을 서로 다른 실루엣과 실제 층고·출입 구조로 제작한다. 개척지의 작업장·운송 시설·폐설비와 광산의 출입/지원동도 별도 목적에 맞춘다.
- 런타임에서 기존 창문·문·층고 전체를 비균일 스케일로 늘여 대형 건물을 만드는 납품은 금지한다. 높이/폭의 변형이 필요하면 실제 층·동·중정·설비/보행 접속을 설계한 크기별 모델 또는 제작 의도가 있는 모듈 조립 구성을 제공한다. 같은 물건의 복제 배치·방향 회전은 허용한다.
- +X 전방·+Y 측면·+Z 위, 미터 단위, 기존 원점/조립 계약을 따른다. 플레이어 1.8m, 게임 1월드 단위=2m를 기준으로 문/계단/보행 폭/차량 진입부를 실측한다. 도시 배치의 기본 축은 헤일로와 같고 고정 쿼터뷰에서 45도로 보인다. 임의의 보정 회전이나 재중앙화를 메시 안에 굽지 않는다.
- asset_id별 실제 크기, 지면 피벗, 출입구/차량 입구·보행 접속점, 권장 대지/도로 후퇴선, 충돌 envelope와 지붕/외벽 가림 구분을 명시한다. 렌더 bounds 전체를 보행 충돌로 쓰지 않아도 되도록 실제 통행 가능한 공간을 제공한다.
- 공통 카툰 렌더 재질과 SF 개척 문명 콘셉트를 유지한다. 상세 원본을 먼저 제작하고 기존 `AGENTS.md`의 파트별 예산(최대 200삼각형)·토폴로지 정리·한도 우회 분할 금지를 따른다. 실제 건축 모듈 구분과 예산을 피하기 위한 임의 분할을 구별한다.
- 납품 시 원본/최적화본·조립 메타데이터·실측 치수·45도 쿼터뷰 및 출입구/차량 접근 비교를 제공한다. 클라이언트는 새 asset_id·실측 크기/출입 계약을 연결한 뒤 현재 `ContentLayout`/`DrawSurfaceStructure`의 테스트용 메시 크기 맞춤 경로를 교체한다. 현재 스케일 맞춤 경로를 정식 자산 계약으로 확정하지 않는다.

## CQ-02A 후속 — 건물 바닥·기초·지형 접지 계약 보충 (2026-11-03)

**요청 상태:** 기존 건물을 삭제하거나 재제작하는 지시가 아니라, CQ-01E의 실측 크기 건물 납품에 필요한 접지 메타데이터 보충이다. 원본은 먼저 정밀하게 제작하고 기존 파트별 삼각형 예산을 지킨다.

- 건물별로 미터 단위 `ground_contact_z_m`(지면 기준), `floor_surface_z_m`(보이는 바닥), 기초/스커트 유무·깊이, 수평 바닥 범위, 출입구 문턱·계단/경사로 높이, 충돌 범위와 실제 피벗을 제공한다. 이것들은 **납품할 정보 항목**이며 현재 로더가 이 필드 이름들을 자동 파싱한다는 뜻은 아니다.
- 지형을 덮는 바닥판·기초 상판을 동일한 Z에 중복 배치하지 않는다. 메시 안에 두 겹의 공면 바닥이 있으면 원본에서 정리한다. 표식/장식은 의도된 별도 높이 또는 재질 표현으로 구분하고, 엔진의 깊이 검사를 끄거나 과도한 depth bias를 전제로 납품하지 않는다.
- 경사지용 기초/스커트는 불투명 측면으로 지형까지 이어져 공중에 뜬 틈이 보이지 않게 한다. 지면 기준을 바꾸기 위한 임의 재중앙화·전체 메시 축 변환은 하지 않는다. 지하실이나 실제 출입구는 자동 기초 상자로 막지 않도록 개구부 범위를 함께 명시한다.
- 현재 테스트 렌더는 건물 하단을 기준 지면보다 0.08m 올리고 기초 상판을 0.10m에 두어 0.02m 겹쳐 접지한다. 충돌체·도로 접속 높이를 같이 올리지 않는다. 새 배치는 대지 5×5 표본의 최고 높이를 기준으로 한다. 이 임시 수치를 원본 메시에도 중복으로 굽지 않는다. 새 접지 계약을 로더에 연결할 때 자산별 지면/바닥·개구부를 사용하고 테스트 보정을 대체해야 한다.
- 45도 쿼터뷰에서 정지·이동/줌, 평지·완만한 경사, 가까운 보도/도로, 낮은 태양/그림자 장면을 비교한다. 바닥 격자 깜빡임, 노출된 틈, 문턱/플레이어 1.8m 스케일, 저해상도 모드 판독을 검수한다. 게임 빌드·GPU/FPS 검증은 별도다.

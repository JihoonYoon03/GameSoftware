# 애니메이션 블렌딩 연결 상태와 추가 모션 요청

2026-10-28. 게임 코드에 이동 1D 블렌드, 조준 이동 2D 블렌드, 본별 상체 레이어와 신규 권총 운반·재장전을 연결했다.

## 이미 납품되어 연결한 모션

- `Idle`, `Walk`, `Run`: 속도에 따른 이동 블렌드.
- `Aim_Base`, `Aim_Walk_*`, `Aim_Run_*`: 정지 조준과 전진·후진·좌우·대각선 8방향 조준 이동. 후진 클립은 이미 있으므로 새로 제작할 필요가 없다.
- `Attack_Fire`, `Attack_Melee`: 이동을 유지하는 상체 공격 레이어.
- `Ride`: 기존 바이크 탑승 자세를 유지한다.
- `Pistol_Carry_Idle`, `Pistol_Carry_Walk`, `Pistol_Carry_Run`: 무장·비조준 상체 운반. 속도와 기존 보행 위상을 공유하고 조준 가중치로 Aim_Base와 전환한다.
- `Reload_Pistol`: 실제 무기 재장전 진행률로 재생한다. 진입/복귀는 0.15초 블렌드이며 이동 하체를 보존한다. 플레이어·광산/1장 전투 NPC·보안대에 연결했다. 탄약 처리는 무기 코드만 담당하고 탈착 탄창 모델은 추가하지 않는다.

조준 이동의 표본·삼각형·축은 `Documentation/aim_locomotion_blending.json`을 따른다. 클립의 위상은 공유하고 방향·속도 변경이나 조준 전환 때 0으로 되돌리지 않는다. 스킨 행렬을 선형 혼합하지 않고 본 로컬 이동/회전/크기를 보간한다. 발 접지는 배우 루트나 충돌 위치를 움직이지 않는 시각 보정이다.

## P1·P2 납품 및 연결 완료

아래는 제작 기준의 보존 기록이다. 두 항목은 `Documentation/PISTOL_LAYERS_ko.md`에 따라 납품되어 게임에 연결되었으므로 재제작 요청이 아니다. 실제 GLB의 63클립과 게임에서 합성하는 Ride를 유지한다.

### P1: 권총을 내리고 운반하는 상체

권총 운반 3종을 상체에 적용한다. 기본 Idle/Walk/Run은 하체 이동을 담당한다.

- 제안 클립: `Pistol_Carry_Idle`, `Pistol_Carry_Walk`, `Pistol_Carry_Run`.
- 오른손으로 권총을 잡고 총구를 아래/안전 방향으로 유지한다. 얼굴·허벅지·의복·가방과 관통하지 않는다.
- 어깨→팔꿈치→손목의 연속 동작으로 무기를 운반한다. 무기만 별도로 움직이지 않는다.
- 상체 마스크: spine/chest/neck/head, 양쪽 clavicle/arm/forearm/hand, weapon_socket/back_socket/muzzle. root·pelvis·하체는 기존 이동 레이어가 담당한다.
- Walk는 1초, Run은 2/3초 루프. 기존 왼발 접지 0, 오른발 접지 0.5와 동기화한다.
- 조준 시작/해제 때 Aim_Base와 0.1~0.2초에 걸쳐 섞어도 손·무기가 튀지 않는지 확인한다.

### P2: 권총 재장전 상체

전용 재장전 클립을 기존 탄창/시간/HUD 규칙의 진행률에 연결했다.

- 제안 클립: `Reload_Pistol`, 1.4초, 비루프, 상체 마스크.
- 오른손은 무기 그립, 왼손은 탄창/슬라이드 쪽에서 동작한다. 머리와 가슴을 관통하지 않는다.
- 실제 탄창 소모·탄약 채움은 게임 코드가 결정한다. 애니메이션 이벤트가 탄약을 중복 지급하지 않는다.

### 속도 범위 확인

현재 게임의 빠른 이동은 납품 Run(2.46m/s)과 조준 Run(방향별 1.2~1.8m/s) 표본 범위를 넘을 수 있다. 범위 밖에서는 외곽 표본으로 투영하고 재생 속도를 제한한다. 향후 실제 이동 속도를 조정하거나, 이 속도에 맞는 전진 스프린트/빠른 조준 이동 클립이 필요하다. 기존 후진을 앞걸음 클립의 역재생으로 대체하지 않는다.

## P0: 출발·제동·180도 달리기 전환 — 2026-10-29 신규 요청

게임에 도보 가감속과 반대 입력 시 감속→회전→재가속, 바이크 속도 벡터/접지 회복을 구현했다. 현재 도보는 기존 Idle/Walk/Run과 작은 spine 균형 보정을 사용한다. 아래 발 디딤·무릎 굽힘·골반 체중 이동은 전용 신규 제작이 필요하며 **아직 전용 클립이 연결된 상태가 아니다**.

### 동세 기준

- 2026-10-29 [Mixamo 회전 목록](https://www.mixamo.com/#/?page=2&query=turn&type=Motion%2CMotionPack)의 **Running Turn 180 / Turning 180 Degrees While Running** 공개 3D 미리보기를 직접 확인했다. 달리던 힘을 넓어진 지지 발과 낮아진 골반으로 받고, 반대 방향으로 몸을 돌려 발로 다시 밀어내는 자세를 참고한다. 해당 파일을 다운로드·리타기팅하지 않았다. GTA5 동작을 실제 분석한 결과라고 표기하지 않는다.
- 단순히 달리기 모션을 180도 회전하거나 역재생하지 않는다. 제동 때 몸이 뒤로 버티고, 출발 때 전방으로 기울며, 좌/우 회전에서 지지 발과 골반·가슴의 회전 시차를 표현한다. 발을 바닥 위로 미끄러뜨려 배우 회전을 흉내 내지 않는다.

### 요청 클립과 연결 계약

| 우선순위 | 제안 클립 | 용도 |
|---|---|---|
| P0 | `Run_Start_Left`, `Run_Start_Right` | 정지→이동. 0.15~0.30초 가속에 맞춰 양쪽 시작 발 제공 |
| P0 | `Run_Stop_Left`, `Run_Stop_Right` | 이동→정지. 0.10~0.25초 제동·무게 회수 |
| P0 | `Run_Turn180_Left`, `Run_Turn180_Right` | 빠른 반대 입력. 제동·접지·반전·반대 방향 재출발, 약 0.35~0.60초 |
| P1 | `Walk_Start`, `Walk_Stop`, `Turn90_Left`, `Turn90_Right` | 느린 출발/정지와 완만한 방향 전환 |
| P1 | 조준 스트레이프 출발/정지의 앞·뒤·좌·우 변형 | 조준 방향을 고정한 상태에서의 가감속. 기존 8방향 조준 이동은 보존 |

- HUMAN_7H 23본과 기존 63개 납품 클립·바인드·스킨·무기/헤어/의복 부착점을 보존한다. 합성 `Ride`는 별도 런타임 동작이므로 새 원본으로 덮어쓰지 않는다.
- **in-place**로 제작한다. root의 위치·yaw는 0으로 두고 실제 이동 궤적과 배우 yaw는 게임의 `PlayerMotion`이 소유한다. 골반·가슴·발의 상대 운동을 제작하되 배우 회전과 중복된 180도 root 회전을 굽지 않는다. 실제 배우 회전 곡선에 맞춘 검토 씬을 함께 제공한다.
- `brake_plant`, `turn_mid`, `push_off`, `recover` 표식을 정규화 시간과 함께 납품한다. 프레임 번호만 고정하지 않는다. 게임은 속도·입력·`pivoting` 상태와 실제 회전각을 판단하며, 이벤트는 위치 변경·순간 속도 변경·입력 잠금에 사용하지 않는다.
- 플레이 테스트 결과 이동 응답은 130%로 고정했고 테스트 슬라이더는 제거했다. 도보 최대 속도는 3.2월드/초이며 실제 가속은 18.2월드/초²·제동은 28.6월드/초²다. 이 고정 응답에서 재생 속도와 블렌드 길이를 맞춘다. 월드 크기는 기존 `WorldScale`을 따른다. 빠른 입력 변경 때 중단/재블렌드할 수 있어야 하며 클립 종료까지 강제 대기시키지 않는다.
- 무장 비조준 상태에서도 같은 이동 전환 하체에 운반 상체를 유지한다. 조준 중에는 180도 전신 회전 클립을 강제로 사용하지 않고 기존 조준 방향/스트레이프 블렌드를 유지한다. 사격·재장전 상체의 우선순위와 실제 총구를 보존한다.
- 남녀 체형·중장비 의복·가방·헤어와 검토한다. 발 접지, 골반 높이, 몸 회전과 손/무기 관통을 검사한다. 출발/정지 및 이동 위상별(왼발·오른발 접지) 진입/복귀 미리보기를 제공한다.

## 보존·납품 조건

기존 HUMAN_7H 23본, 본 이름/순서/부모, 바인드·스킨·의복·부착점과 기존 59개 클립을 보존한다. 루트 이동/yaw는 0이고 실제 이동·회전·충돌은 게임이 소유한다. 새 클립은 기존 캐릭터 GLB와 공통 조립 계약에 추가하며, 모션마다 캐릭터 파일이나 스켈레톤을 복제하지 않는다. 게임 Runtime은 모델링 작업에서 수동 편집하지 않는다.

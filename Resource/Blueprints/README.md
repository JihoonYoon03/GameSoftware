코트·바지는 회색 T포즈 마네킹, 헤어는 회색 두상에 착용한 뷰입니다. 장비는 단독으로 제작했습니다. L/R은 캐릭터 기준입니다. 손은 손등이 정면이며, 파우치는 덮개가 정면입니다. 구조팩 방향은 캐릭터가 착용한 상태를 기준으로 합니다.

각 파츠 안에서 높이와 기준선을 맞췄습니다. 파츠 간 크기는 원화에서 확인합니다. 원화에서 가려진 내부 구조는 그림 제작 과정에서 보완한 형태입니다.

# 도시 충돌·치안 대응 애니메이션 제작 요청서

2026-10-23 · SF 개척지 보안망 / 물리 판정과 분리된 반응 애니메이션

## 현재 게임 연결

도시에서 좌클릭 권총 사격, R 재장전, V 근접 공격을 사용한다. 사격·조준은 기존 클립을 사용하며 근접 공격에는 기존 `Attack_Melee`를 연결했다. 총기는 손/팔 본을 따라간다. 새 충돌 전용 클립은 아직 제작하지 않았다.

`Game.h`의 `BodyImpact`는 `response`, `velocity`, `seconds`, `invulnerability`를 제공한다. `BodyResponse`는 `None`, `Stagger`, `Knockdown`, `Dead`다. `velocity`는 월드 좌표의 충격 속도이며 1월드 단위=2m다. `Civic.cpp`의 `BodyCollision`이 이동·분리·충격 감쇠를 처리한다. 클립이 루트 위치나 충돌체를 다시 움직여서는 안 된다.

- 일반 주민: `Resident.health`, `Resident.impact`, `fearSeconds`, `corpseSeconds`.
- 플레이어: `CivicJustice::State().playerImpact`. 쓰러져 체력 0이 되면 `HospitalRecovery`가 입력을 잠그고 의료소로 이송한다.
- 보안대: `SecurityOfficer.health`, `impact`, `tier`, `muzzleFlash`. 1~2단계 Guard, 3~5단계 HeavyCombat 외형을 사용한다.
- 차량: `TrafficVehicle.health`, `impactCooldown`, `hitFlash`, `wreckSeconds`. `health<=0`이면 동력 차단 잔해이며 충돌체는 유지된다. 도로 진행/회전과 파괴 상태가 애니메이션에 종속되지 않는다.
- 서사 NPC: 리아·마라·카인은 중상 시 상호작용을 멈추고 의료 지원 후 복귀한다. 일반 주민과 보안대의 사망 상태와 구분한다.

현재 피격은 충격 이동, 근접은 기존 상체 클립, 넘어짐/사망은 정적인 누운 자세로 임시 표현한다. 아래 클립을 제작하고 런타임 선택/이벤트를 연결해야 충돌 연출이 완성된다.

| P2 | `Medical_Stabilized`, `Medical_GetUp` | 짧은 회복/기립 | 병원 페이드 후 선택적으로 사용할 안정화 동작. 병상/구급차 장면은 현재 범위에 포함하지 않는다. |

반응 방향은 충격의 월드 벡터를 캐릭터 로컬 방향으로 변환해 선택한다. 제작 시 +전방/+좌측 축을 기존 HUMAN_7H와 동일하게 유지한다. 표기 이름은 통합 제안이며 현재 게임이 이미 이 이름들을 자동 선택한다는 뜻이 아니다.

| P2 | `Wreck_TowOut` 또는 페이드 이벤트 | 교차로를 영구히 막지 않도록 잔해를 정리하는 후속 연출. 현재는 화면 밖 또는 충분한 시간이 지난 뒤 정리한다. |

추진 불꽃·스파크는 기존 깊이 검사 2D 빌보드를 재사용한다. 이 요청을 이유로 3D 삼각형 불꽃이나 노출 프로펠러를 추가하지 않는다.

## 제작·납품 계약

1. 기존 `Resource/AGENTS.md`와 캐릭터 상세 조립 규칙을 따른다. HUMAN_7H 23본·기존 15클립·게임용 Ride, 성별/체형 6종, 피부색·외장·의복·장비 오프셋을 보존한다. 새 클립을 추가하기 위해 기존 애니메이션이나 부품을 제거하지 않는다.
2. 편집 가능한 원본과 GLB, 클립별 실제 길이·반복 여부·블렌드 구간·지지 발·진입/종료 포즈·이벤트 시간을 제공한다. 공통 원점·미터 단위·축·바인드 포즈를 유지한다.
3. 무기/장비/머리카락·헬멧·외장 하네스의 관통을 남녀·Lean/Normal/Heavy 조합과 걷기/사격/넘어짐 전환에서 확인한다. 고정된 콜리전과 장비 접속 위치는 변경하지 않는다.
4. 통합 시 반응 클립 선택, 기립 중 입력 잠금, 범죄/피해의 중복 적용 방지, 병원 페이드, 사망 후 재생 정지, 최대 10명 생존 보안대/100명 주민의 갱신 비용을 검증한다.
5. 모델링 작업은 게임 코드·`Resource/Runtime` 캐시를 수정하지 않는다. 원본 납품 후 게임 작업에서 변환·등록·상태 연결을 진행한다. 이 문서는 제작 요청용이며 신규 클립 제작 완료를 뜻하지 않는다.

# 도시 충돌·치안 대응 애니메이션 제작 요청서

2026-10-23 · SF 개척지 보안망 / 물리 판정과 분리된 반응 애니메이션

## 현재 게임 연결

도시에서 좌클릭 권총 사격, R 재장전, V 근접 공격을 사용한다. 사격·조준은 기존 클립을 사용하며 근접 공격에는 기존 `Attack_Melee`를 연결했다. 총기는 손/팔 본을 따라간다. 최초 요청 당시에는 충돌 전용 클립이 없었다. 현재 납품 상태와 남은 연결 범위는 마지막의 2026-11-03 확인 기록을 따른다.

`Game.h`의 `BodyImpact`는 `response`, `velocity`, `seconds`, `invulnerability`를 제공한다. `BodyResponse`는 `None`, `Stagger`, `Knockdown`, `Dead`다. `velocity`는 월드 좌표의 충격 속도이며 1월드 단위=2m다. `Civic.cpp`의 `BodyCollision`이 이동·분리·충격 감쇠를 처리한다. 클립이 루트 위치나 충돌체를 다시 움직여서는 안 된다.

- 일반 주민: `Resident.health`, `Resident.impact`, `fearSeconds`, `corpseSeconds`.
- 플레이어: `CivicJustice::State().playerImpact`. 쓰러져 체력 0이 되면 `HospitalRecovery`가 입력을 잠그고 의료소로 이송한다.
- 보안대: `SecurityOfficer.health`, `impact`, `tier`, `muzzleFlash`. 1~2단계 Guard, 3~5단계 HeavyCombat 외형을 사용한다.
- 차량: `TrafficVehicle.health`, `impactCooldown`, `hitFlash`, `wreckSeconds`. `health<=0`이면 동력 차단 잔해이며 충돌체는 유지된다. 도로 진행/회전과 파괴 상태가 애니메이션에 종속되지 않는다.
- 서사 NPC: 리아·마라·카인은 중상 시 상호작용을 멈추고 의료 지원 후 복귀한다. 일반 주민과 보안대의 사망 상태와 구분한다.

현재 피격은 충격 이동, 근접은 기존 상체 클립, 넘어짐/사망은 정적인 누운 자세로 임시 표현한다. 아래 클립을 제작하고 런타임 선택/이벤트를 연결해야 충돌 연출이 완성된다.

## 제작·납품 계약

1. 기존 `Resource/AGENTS.md`와 캐릭터 상세 조립 규칙을 따른다. HUMAN_7H 23본·기존 15클립·게임용 Ride, 성별/체형 6종, 피부색·외장·의복·장비 오프셋을 보존한다. 새 클립을 추가하기 위해 기존 애니메이션이나 부품을 제거하지 않는다.
2. 편집 가능한 원본과 GLB, 클립별 실제 길이·반복 여부·블렌드 구간·지지 발·진입/종료 포즈·이벤트 시간을 제공한다. 공통 원점·미터 단위·축·바인드 포즈를 유지한다.
3. 무기/장비/머리카락·헬멧·외장 하네스의 관통을 남녀·Lean/Normal/Heavy 조합과 걷기/사격/넘어짐 전환에서 확인한다. 고정된 콜리전과 장비 접속 위치는 변경하지 않는다.
4. 통합 시 반응 클립 선택, 기립 중 입력 잠금, 범죄/피해의 중복 적용 방지, 병원 페이드, 사망 후 재생 정지, 최대 10명 생존 보안대/100명 주민의 갱신 비용을 검증한다.
5. 모델링 작업은 게임 코드·`Resource/Runtime` 캐시를 수정하지 않는다. 원본 납품 후 게임 작업에서 변환·등록·상태 연결을 진행한다. 이 문서는 제작 요청용이며 신규 클립 제작 완료를 뜻하지 않는다.

## CQ-02A 확인 — 충돌 기능 복원과 납품 구분 (2026-11-03)

`Documentation/civic_animation_contract.json`은 HUMAN_7H 23본·인체 82클립·차량 신규 21액션과 편집 원본/내보내기/검증 자료를 기록하고 있다. 따라서 위의 Hit·Knockdown·Downed·GetUp·Death·차량 반응을 **새로 중복 제작하지 않는다**. 원본/리그/기존 클립은 보존한다. 계약의 `runtime_implementation_included: false` 및 `game_integration_checks_pending`도 함께 읽어야 하며, 납품을 게임 전체 연결 완료로 해석하지 않는다.

이번 게임 수정은 바이크의 구면 이동 전 구간과 차체 회전을 검사하여 도시 주민·서사 NPC·보안대·동료·일반 절차 지역 인물·개척지 인물의 접촉 피해를 복원한다. 충돌체 이동·피해·미끄러짐/후진 탈출은 게임 물리가 소유한다. 이 수정만으로 모든 인물에 방향별 넘어짐·완전 기립 이벤트를 연결했다고 표시하지 않는다. CQ-05/06/07에서 피격 방향·무기/하체 블렌드·서사 NPC 회복·기립 완료 이벤트와 실제 입력 잠금 시간을 계약대로 연결하고 확인한다.

신규 충돌 모션 요청은 현재 없다. 일반 자동차의 탑승·하차 연출은 아래 CQ-06B 항목을 참고한다. 비행체와 라그돌/낙차는 해당 단계에서 별도 확정한다.

## CQ-06B 지상 공용차 승하차 요청 (2026-11-09)

- 기존 Coupe의 문 손잡이·문축·운전석·핸들 접점을 차량 로컬 미터 좌표로 제공한다. 문과 핸들이 이미 리그에 분리되어 있다면 본과 접점을 재사용한다.
- HUMAN_7H 기준 접근 방향별 승차, 운전석 기본 자세, 하차 클립을 요청한다. 한쪽 문이 막혀 반대쪽 출구를 쓰는 자세도 지원한다. 좌석 접촉·문 개폐·지지 발 착지 시점, 블렌드 가능 구간을 납품표에 기록한다.
- 게임이 안전한 출구·좌석 위치와 피해·파괴를 결정한다. 클립의 루트 모션이나 이벤트가 차량과 캐릭터의 실제 위치를 덮어쓰지 않도록 하고, 성별·체형·의복 조합에서 얼굴·차체 관통을 점검한다.

## CQ-06C 공용 비행체 승하차 요청 (2026-11-11)

- 현재 Courier 원본의 크기·원점·축·분절 부상 필드와 발광 코어를 유지한다. 조종석 좌석·조종 접점과 지상 출입 위치를 기체 로컬 미터 좌표로 제공한다.
- 기존 HUMAN_7H 클립을 보존하고, 지상 승차/하차·조종석 기본 자세·상승/선회/착륙 반응을 기존 납품과 대조하여 필요한 항목만 제작한다. 접촉 시점과 전환 구간을 명시한다.
- 비행 이동·고도·착륙 공간·파괴/운전자 이탈은 게임이 결정한다. 현재 게임은 즉시 탑승·착륙 후 하차를 사용하며 조종석 인체 연출은 아직 연결하지 않았다. 새 원본/클립 제작·런타임 팩 재생성은 이번 코드 단계에 포함하지 않는다.

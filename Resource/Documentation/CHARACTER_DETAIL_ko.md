## 바뀐 형태

- **몸체:** 흉곽·허리·골반·사지의 곡선 단면과 중간 윤곽을 보강했습니다. 1.8m·7등신 기준, 체형별 비율과 관절 끝 위치를 유지합니다.
- **머리·얼굴:** 턱·광대·이마의 높이별 단면을 다시 작성했습니다. 눈 흰자·동공·눈꺼풀·눈썹·콧대·콧방울·입술을 별도 형상으로 표현합니다. 얼굴 표정 3종과 머리 양식 4종은 계속 교체 가능합니다.
- **손:** 덩어리 손 대신 손바닥·네 손가락·엄지와 손톱을 표현했습니다. 손가락 형상은 기존 손 본을 따르며 새로운 개별 손가락 본을 추가하지 않았습니다.
- **부츠:** 발끝 보호대·뒤꿈치 보강·밑창 트레드·조임 장치를 만들고 밑창 최저점을 지면에 맞췄습니다.
- **의복:** 봉제선·지퍼·체결구·작은 상태 표시와 장갑 겹침을 보강했습니다. 정비복·전투복·의료복·연구복 등의 원래 역할별 실루엣은 유지합니다.
- **장비:** 인간 크기의 장비에 맞춰 모서리를 다듬고 서비스 커버·잠금부·표시등·바이저 테두리·환기 슬릿을 추가했습니다. 부착 소켓과 체형별 오프셋은 유지합니다.

## 조립 규칙

기존 `Outfit_역할_체형_Torso` ID는 옷감 본체와 코트 자락을 나타냅니다. 대응하는 `..._Torso_OuterAssembly`는 가슴 장갑·하네스·외부 여밈 장치를 나타냅니다. 삼각형 수로 임의 분할한 조각이 아니라 실제로 분리 가능한 착용 레이어입니다.

`character_detail_assemblies.json`의 `outer_assemblies`에서 대응 파트를 확인합니다. **Torso와 그에 맞는 OuterAssembly를 함께 선택**하면 완성 의복이 됩니다. 완성 캐릭터 GLB와 `assembly_recipes.json`의 인물 10종에는 이미 양쪽 파트가 포함되어 있습니다. 체형 이름이 다른 의복과 혼용하지 마십시오. 각 `Export/Modules/*.glb`는 독립 메시 하나를 유지합니다.

공통 `HUMAN_7H`의 **23개 본·15개 애니메이션**, 미터 단위, 공통 바인드 좌표, 기존 피부색 조합과 장비 오프셋을 유지합니다. 몸통의 chest/spine 혼합 가중치와 코트 자락의 허벅지 연결을 상세 원본과 최적화본 양쪽에 적용했습니다. 맨몸과 옷의 겹치는 슬롯을 숨기는 기존 규칙도 유지합니다.

## 파일과 확인 장면

- `Source/Erma_Resource_Library.blend`: 기존 캐릭터와 조립·검토 장면을 새 메시로 갱신한 원본. 기본 진입 장면은 기존 통행로 예제입니다.
- `25_Character_Detail_Sources`: 최적화 전의 편집 가능한 상세 원본. 이전 비교 형상도 별도 컬렉션에 보관했습니다.
- `26_Character_Detail_Comparison`: 탐사·정비·중장갑·일상 인물의 이전/개선 조립 비교.
- `27_Character_Detail_Closeups`: 얼굴·손·부츠·옷감/하네스 확대. 비교용 표시 크기이며 실제 납품 크기는 바꾸지 않았습니다.
- `28_Character_Head_Study`: 머리 4종과 표정 검토.
- `Preview/29_character_detail_comparison.png`, `30_character_detail_closeups.png`, `31_character_heads.png`: 위 장면의 렌더.
- `Export/Characters/*.glb`: 개선 파트로 다시 조립한 캐릭터 10종.
- `Export/Modules/*.glb`: 기존 ID를 유지한 교체 파트와 새 OuterAssembly.
- `Validation/character_detail_pipeline_report.json`: 854개 상세 원본/최종 수치와 외부 표면 오차.
- `Validation/character_detail_report.json`: 원본/최종 스킨, 체형 비율, 전체 인물의 GLB 재가져오기와 동작 검사.

## 재제작

Blender에서 `Tools/build_character_detail_expansion.py`를 실행합니다. 이 도구는 현재 라이브러리를 열어 인체 관련 파트만 갱신하고, 이동수단·건물·통행로 등의 형상을 해시로 대조해 보존합니다. `-- --geometry-check`는 납품 파일을 덮어쓰지 않고 상세 제작과 500개 상한만 검사합니다. `-- --preview-only`는 저장본·GLB를 바꾸지 않고 비교 렌더만 만듭니다.

전체 팩을 처음부터 재제작할 경우 공통 원본 → air/city → transit → refined city → character detail 순서입니다. 부분 갱신을 위해 공통 원본 제작기를 실행하지 마십시오. 검증은 일반 Python의 `verify_resource_pack.py`와 Blender의 `verify_character_details.py`를 사용합니다.

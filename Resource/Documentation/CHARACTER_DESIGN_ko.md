# 체형 · 의복 · 부착 파트 확장판

## 체형 6종

기존 Standard / Slender / Broad는 **기존 정상 체형의 기준·호환 자료**로 보존했습니다. 새 선택 규격은 다음 6종입니다. 기존 Slender를 새 마른 체형으로 단순 재분류하지 않았습니다.

| 새 이름 | 표현 | 주요 형상 |
|---|---|---|
| Male_Lean | 마른 남성형 | 좁은 흉곽, 얇은 복부와 사지, 비교적 작은 골반 |
| Male_Normal | 정상 남성형 | 넓은 어깨와 V자 흉곽, 정상 복부·사지 |
| Male_Heavy | 살찐 남성형 | 두꺼운 흉곽, 앞으로 나온 복부, 넓은 허리와 두꺼운 사지 |
| Female_Lean | 마른 여성형 | 작은 어깨, 뚜렷하게 좁은 허리, 상대적으로 넓은 골반 |
| Female_Normal | 정상 여성형 | 어깨·허리·골반 차이와 흉부 볼륨, 완만한 허벅지 윤곽 |
| Female_Heavy | 살찐 여성형 | 넓은 골반과 두꺼운 허벅지, 복부와 흉부 볼륨, 남성형과 다른 어깨 비율 |

머리 높이와 다리 길이를 바꾸지 않고 몸통 단면·복부의 앞뒤 깊이·골반·사지 두께를 각각 바꿨습니다. 맨머리 1.8m·7등신 기준과 기존 23본 `HUMAN_7H`를 공유합니다. 머리·헤어·얼굴·색은 체형 선택과 독립적입니다. 베이스 인체의 이름은 `Body_체형_Chest/Abdomen/Pelvis/UpperArm_L/...`입니다.

`07_Body_Profiles` Scene과 `Preview/06_body_profiles.png`에는 6종의 정면·측면을 같은 키와 중립 재질로 배치했습니다. 수치와 형태 파라미터는 `body_profiles.json`, 실측 단면은 `Validation/design_report.json`에 있습니다.

## 형태가 다른 의복 9종

각 의복의 전체 세트는 6개 체형 모두에 맞춘 Torso, 좌우 Sleeve/Cuff/Trouser/Greave로 나뉩니다. 같은 체형 이름의 파트를 조합합니다.

| 목적 | 실루엣과 기능 요소 |
|---|---|
| Explorer · 탐사 | 분할 흉부 셸, 높은 압력 목씰, 탐사 하네스, 경량 손목 장비 |
| Engineer · 정비 | 비대칭 공구용 가슴받이, 사선 작업 벨트, 두꺼운 말림 소매, 공구 주머니 |
| Guard · 전술 경비 | 분절형 방탄 조끼, 독립 어깨 장갑, 전완·무릎·정강이 방호판 |
| Medic · 의료 | 하단이 넓은 임상용 조끼, 갈라진 앞치마, 둥근 퍼지 포트, 손목 진단기 |
| Researcher · 연구 | 긴 분할 코트 앞뒤 자락, 비대칭 여밈, 높은 옷깃, 센서 소매 |
| Miner · 채굴 | 외부 늑골형 방호판, 충격 어깨 캡, 대형 작업 건틀릿, 무릎·정강이 보강 |
| HeavyCombat · 중장갑 전투 | 크게 부푼 동력 흉갑, 대형 다층 어깨, 두꺼운 다리 장갑과 외골격 레일 |
| Pilot · 조종 | 밀착형 비행복, 소형 호흡기, 유연한 팔다리, 골반 구속 스트랩과 비행용 커프 |
| Civilian · 일상 | 열린 유틸리티 재킷, 접힌 옷깃, 천 주머니, 부드러운 바지·말린 밑단 |

Torso의 형상 해시는 목적마다 다릅니다. 색을 모두 같은 재질로 덮은 `08b_Outfit_Silhouette_Check` Scene과 `Preview/08_outfits_grayscale.png`도 제공하여 색을 제거한 상태에서 실루엣 차이를 확인할 수 있습니다. 얇은 옷의 몸통 아래쪽은 spine/chest 사이로 스킨 가중치를 나눴고, 긴 코트 자락은 허벅지 본을 따릅니다.

## 액세서리 34개

액세서리는 의복에 합쳐진 면이 아니라 `Accessory_*`라는 **별도의 메시 파트**입니다. 백팩, 흉부, 허리, 좌우 골반·어깨·전완, 머리, 오른손의 11개 부착 위치를 정의했습니다. 원본에는 `ATTACH_*` Empty가 있고, `accessory_sockets.json`에 부착 본과 기준 위치를 저장했습니다. 기존 스켈레톤의 본은 추가하거나 이름을 바꾸지 않았습니다.

- 백팩: 이중 산소통, 채굴용 전원 리그, 전투용 반응로, 의료 구조 팩, 연구용 샘플 랙, 조종용 소형 팩, 일상용 배낭.
- 흉부·허리: 탐사 콘솔, 주사 카트리지 랙, 산업용 호흡 필터, 다층 방호 흉판, 생명유지 벨트.
- 좌우 부위: 전술·중장갑 어깨 캡, 작업등, 손목 스캐너, 의료 주입 도구, 유틸리티 파우치, 의료 파우치, 공구 말이.
- 머리: 보호 고글, 채굴 안전모, EVA 밀폐 헬멧, 전술 헬멧, 중장갑 헬멧, 연구용 안면 실드.

장비 파트는 인체와 같은 **공통 바인드 포즈 좌표**로 제작했습니다. 부착 Empty의 로컬 원점에 그대로 중복 이동시키지 않습니다. 게임에서 메시를 결합할 때는 같은 본 이름과 바인드 행렬을 공유하고, 조립 레시피의 `offsets`를 적용합니다. 체형별 복부·등 깊이가 다르므로 흉부/백팩/골반 파우치에는 추가 오프셋이 있습니다. 레시피의 오프셋은 미터 단위의 인체 로컬 위치입니다. `accessory_fitting_offsets.json`에는 6체형 × 9의복 × 34액세서리의 오프셋을 모두 저장했습니다.

의복의 가려지는 맨몸 슬롯을 숨기는 규칙은 기존과 같습니다. 밀폐 헬멧에는 헤어를 숨기고, 채굴 안전모에는 HatClearance 헤어를 씁니다. 두 장비가 같은 부착 공간을 차지하면 하나를 선택하거나 별도 여유 공간을 확인합니다. 역할별 기본 장비 세트는 교체 가능한 조합 예제입니다.

## 아트 참고와 이 팩의 해석

다음은 사용자가 지정한 작품의 공식 자료를 확인하고, 헤일로의 로우 폴리 리소스에 맞게 해석한 설계 방향입니다. 아래의 역할 배분과 형상은 이 팩의 제작 판단입니다.

- Dead Space: 산업·정비 환경과 엔지니어 장비의 용도를 참고해 채굴복의 외부 보강 리브, 공구 하네스, 작업등을 구성했습니다. [EA 공식 소개와 코스플레이 가이드 링크](https://www.ea.com/nl/games/dead-space), [EA의 산업 공간 제작 설명](https://www.ea.com/able/news/inside-dead-space-3-aboard-the-ishimura).
- Pragmata: 밀폐 우주 작업복과 부품 분할의 인상을 탐사복·조종복의 압력 목씰, 세라믹 셸, 생명유지 팩으로 해석했습니다. [Capcom 공식 소개](https://us-store.captown.capcom.com/blogs/news/0000010), [공식 계정의 수트 부품 아트 안내](https://x.com/PRAGMATAgame/status/1989015572625961440).
- Star Citizen: 언더수트와 장비 레이어를 구분하는 조합 개념을 독립 액세서리, 용도별 팩, 수납·교체 파트에 반영했습니다. [공식 장비 가이드](https://support.robertsspaceindustries.com/hc/en-us/articles/360007262334-Equipping-Your-Character), [공식 캐릭터 아트 작업 보고](https://robertsspaceindustries.com/en/comm-link/transmission/18296-Star-Citizen-Monthly-Report-August-2021).
- StarCraft II: 멀리서도 읽히는 중장갑 실루엣을 크게 분리한 흉갑·어깨 캡·다층 다리 장갑으로 해석했습니다. [Blizzard 공식 Marine 의상 제작 소개](https://news.blizzard.com/en-gb/article/9991457/what-does-it-take-to-make-a-true-marine).

외부 게임의 모델·텍스처·문양은 리소스에 넣지 않았습니다. 이 팩의 메시와 재질은 Blender에서 새로 생성한 것입니다.

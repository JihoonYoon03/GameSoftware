# 인간 캐릭터 도면 기반 리메이크 v4

2026-11-24 · 편집 원본, 조립용 메시, 검토 렌더 납품

## 도면 반영 범위

- 남성·여성 각 3체형을 다시 제작했다. 어깨·흉곽·허리·골반·팔다리 폭은 체형별로 조정했고, 기존 23본 리그의 관절 위치와 미터 단위 부착 좌표를 적용했다. 머리 형태 4종, 표정 파츠 3종, 헤어 7종, 손·발·부츠도 다시 제작했다.
- 탐험가의 쌍통 생명유지 장치와 전면 항법 장치, 경비의 분절식 흉갑·어깨 장갑, 의무병의 카트리지 랙과 구조 배낭, 조종사의 하네스·바이저, 항만 주민의 재킷·배낭에 직업별 도면을 적용했다. 공학자·연구원·광부·중장 경비는 기존의 직업별 장비 구성을 이어받아 새 체형에 맞췄다. 의상 9종에 각 6체형 피팅을 제공한다.
- 2D 시트의 콘셉트 그림은 외곽·색상·재질 참고에 사용했다. 부착 크기와 위치는 시트의 실측 뷰, 기존 에셋 경계, 조립 오프셋을 사용했다. 탐험가 여성 체형은 도면 검토용 조립 예시로 추가해, 기존 캐릭터 10명과 함께 총 11개 레시피를 제공한다.
- 장비 파츠 32개를 다시 제작했다. 레시피에서 사용하는 기존 권총은 LOD0·LOD1의 선택 부착물로 기록했으며 해당 삼각형 수도 조립체 예산에 합산했다.

| [HUMAN_7H_Parts.glb](../Export/HumanV4/HUMAN_7H_Parts.glb) | 파트 ID와 LOD가 기록된 단일 GLB. 23본 스킨과 공유 재질·텍스처를 사용한다. |
| [human_reference_v4.json](human_reference_v4.json) | 파트별 경계와 예산, 조립 오프셋, 피부색, 도면·파일 해시, 캐릭터별 조립 레시피 |
| [검수 보고서](../Validation/human_reference_v4_report.json) | 실제 GLB 데이터·바인드·Blender 재가져오기·동작 표본 검사 결과 |

Blender는 복장 검토 장면에서 열린다. 장면 선택 메뉴에서 체형, 장비 후면, 다른 직업, LOD 비교, `HumanV4_Deformation_Review`를 열 수 있다. 동작 장면에서는 기존 걷기·조준·탑승·회피를 재생한다. `HUMAN_7H_V4_Detail_Source`와 `HUMAN_7H_V4_Part_Library`에서는 Outliner에서 해당 컬렉션을 표시한 뒤 같은 `asset_id`의 파트를 선택한다. 각 컬렉션의 파츠는 조립 좌표를 공유하므로 개별 작업 시 격리해 확인한다.

## 최적화와 검수

- 상세 원본을 먼저 만들고 파트 ID별로 보관했다. 납품본은 원본의 단면·관절 제어점·부착 경계를 사용해 면을 배치하고 소형 체결부와 부가 장식을 덜어 냈다. 미세 직물·표면 질감은 공유 맵을 사용한다. 숨겨진 가슴·복부 접합면을 정리하고 양쪽 경계의 스킨 가중치와 법선을 맞췄다.
- [v4 예산표](POLYGON_BUDGET_ko.md)의 크기별 파트 상한과 NPC·주연 조립체 상한을 적용했다. 659개 LOD0 파트는 기존 조립 슬롯을 재사용한다. 원경에서는 얼굴 표현과 작은 센서·파우치 등 착탈 장비를 컬링한다. 인체를 구성하는 손·발·머리와 외곽을 바꾸는 일부 헬멧은 조립체의 일부로 간략화해 남겼다. 그림자용 메시에는 몸통과 사지, 외곽에 영향을 주는 헬멧·배낭을 담았다.
- 불투명 재질은 직물·외장·피부 3개이며 반투명 바이저는 별도 재질이다. 직물과 외장은 각 1024² Base Color(sRGB), Normal(선형, 탄젠트 공간 +Y), ORM(선형, R=AO·G=거칠기·B=금속성) 공유 맵을 타일링한다. GLB의 `COLOR_0`은 선형 색상이다. 피부 재질은 레시피의 인물별 팔레트로 대체한다.
- 인덱스, 삼각형 수, 경계 좌표, UV·탄젠트, 정점색, 스킨 가중치, 재질을 실제 GLB에서 검사했다. 기존 탐험가 GLB와 23본의 순서·부모 관계·역바인드를 비교하고, Blender에서 파트 뱅크를 다시 열어 리그 연결을 확인했다.
- 신규 v4 납품은 R1·R2를 사용하는 게임 로더 통합을 기다리는 상태다. 기존 게임에서는 v3 팩을 사용한다. 기존 모션은 현재 애니메이션 뱅크를 연결하는 구조다.

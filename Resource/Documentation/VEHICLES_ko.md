# 모듈형 차량 5종

헤일로의 SF 부상 차량입니다. 차륜 대신 독립 자기장 포드와 뒤쪽 추진기를 사용합니다. 기본 진행 방향은 기획 문서와 같은 **Blender 로컬 +X**입니다. 인체/몹의 -Y 전방과 다릅니다.

| 타입 | 명목 길이×폭×차체 높이(m) | 용도와 교체 후방 모듈 |
|---|---|---|
| Coupe | 4.30×1.70×1.35 | 민간 부상차 / 후방 데크 ↔ 유틸리티 보관함 |
| Shuttle | 5.60×1.85×2.10 | 여객 셔틀 / 승객실 ↔ 의료 후송실 |
| Hauler | 5.20×1.90×2.00 | 작업·수송차 / 밀폐 적재 컨테이너 ↔ 평상 적재함 |
| Patrol | 4.60×1.75×1.55 | 도시 경비차 / 경광등 ↔ 코일 포탑 |
| JetBike | 2.50×0.95×1.05 | 개방형 탠덤 부상 바이크 / 보관 상자 ↔ 좌우 패니어 |

명목 크기는 모듈 프레임의 설계 기준입니다. 부상 여유는 약 0.18m이며 안테나·포탑·장식과 선택 파트에 따라 실제 외곽은 달라집니다. 미터→현재 게임 월드 단위 변환은 0.5배입니다.

## 같은 타입 안에서 조립

차량 타입마다 자체 프레임·본 위치를 공유합니다. 타입이 다르면 길이/폭과 부착 위치가 다르므로 파트를 직접 혼용하지 않습니다. 같은 타입 안에서는 아래 슬롯의 선택지를 한 개씩 고릅니다.

- Chassis: 기본 차대와 압력 차체.
- Nose: 낮고 날렵한 Sport 전면 ↔ 두꺼운 범퍼·작업등이 달린 Utility 전면.
- Canopy: 파노라마 캐노피 ↔ 분절 장갑 캐노피. 바이크는 일반 윈드스크린 ↔ 랠리 스크린.
- Front/Rear Pod L/R: 표준 포드 ↔ 외장 보강과 경고판이 있는 험지용 포드.
- Engine L/R: 효율형 소형 추진기 ↔ 열교환 핀과 큰 노즐이 있는 부스트 추진기.
- Payload: 타입별 여객실·의료실·적재함·경광등·포탑·보관함.
- Service Hatch: 별도로 움직이는 정비/적재 해치.
- Rail, Underbody: 좌우 보호 레일과 하부 자기장 코일. 바이크에는 좌우 발판도 있습니다.

총 **133개 차량 파트**를 제작했습니다. 모든 파트는 삼각형 변환 후에도 500개 이하입니다. 좌우 포드와 추진기는 독립 파트라 같은 차량에서도 조합을 달리할 수 있습니다. 전체 차대 원점은 지면 중심이며 개별 파트는 공통 차량 바인드 포즈 좌표에 배치되어 있습니다.

`Export/Vehicles/타입.glb`는 A 조립 예제, `타입_Variant.glb`는 B 예제입니다. `Export/Vehicles/Parts`에는 교체용 파트를 리그·스킨과 함께 따로 내보냈습니다. `vehicle_assemblies.json`에 각 타입의 슬롯·가능한 선택지·A/B 기본 조합을 저장했습니다. 완성 차량도 메시를 합치지 않아 파트 이름을 기준으로 교체할 수 있습니다.

## Blender에서 확인

- `09_Vehicles`: 5종의 A 조합과 상대적인 크기.
- `09b_Vehicle_Variants`: 같은 타입의 B 조합.
- `09c_Vehicle_Exploded`: Hauler·JetBike의 부품 분해 배치와 조립 연결선.
- `00_Library` → `VehicleParts_*`: 같은 원점에 놓인 타입별 전체 선택 파트.

분해 배치의 이동은 도감용입니다. 실제 조립은 `Parts`의 바인드 포즈 위치와 레시피를 사용합니다. 운전석·동승자 참조 본 `driver_socket`, `passenger_socket`을 포함했습니다. 탑승자 포즈와 차량 이동 코드는 별도 게임 작업에서 연결합니다.

## 차량 스켈레톤과 애니메이션

각 타입에 16본 리그를 사용합니다. 차체·전면·캐노피·정비 해치·좌우 전후 부상 포드·좌우 엔진·포탑·총구와 탑승 위치를 나눴습니다. 모든 가동 파트는 스킨 가중치로 연결되어 있습니다.

| 클립 | 길이 | 반복 | 내용 |
|---|---:|---|---|
| Vehicle_Reference | 1프레임 | 아니오 | 조립·보간 기준 포즈 |
| Hover_Idle | 2초 | 예 | 작은 부상 상하 리듬과 포드 안정화 |
| Cruise | 1초 | 예 | 순항 시 엔진·포드 미세 움직임 |
| Boost | 1초 | 예 | 큰 추진기 짐벌 동작 |
| Steer_Left / Right | 각 1초 | 아니오 | 전면 포드와 엔진 짐벌을 조향 후 복귀 |
| Canopy_Open / Close | 각 1초 | 아니오 | 캐노피/바이크 스크린의 힌지 개폐 |
| Cargo_Open / Close | 각 1초 | 아니오 | 화물 전체가 아니라 별도 해치 개폐 |
| Vehicle_Fire | 0.4초 | 아니오 | Patrol의 포탑 반동·작은 회전. 포탑 조립에 사용 |

기본 10개, Patrol은 사격을 더한 11개입니다. 30fps, 본별 쿼터니언·위치 키프레임을 포함합니다. 이동은 제자리 애니메이션이며 실제 진행·회전은 Actor가 제어합니다. 차체 전체의 Roll/Pitch를 강제로 추가하지 않았습니다.

Hover_Idle↔Cruise↔Boost는 정규화 위상을 유지하며 0.15초 교차 혼합을 시작값으로 사용할 수 있습니다. 조향은 frontpod와 engine 본을 마스크로 사용하고 Actor의 yaw는 별도로 보간합니다. 캐노피/해치는 해당 본만 오버라이드하고 Open 종료 포즈를 유지하다 Close를 재생합니다. Patrol의 Vehicle_Fire는 turret_yaw/turret_pitch/muzzle만 적용하여 부상·이동 리듬을 유지할 수 있습니다.

GLB 축 변환은 (x,y,z)→(x,z,-y)이므로 차량 전방 +X는 유지되고 위쪽은 +Y가 됩니다. 본·소켓·스킨의 단위와 축은 `skeletons.json`을 따릅니다. 콜리전·주행·탑승·사격 코드는 포함하지 않았습니다.

후속 창호 개선에서 기존 122개 파트를 새 파이프라인으로 교체하고 유리/실링 파트 11개를 추가했습니다. 캐노피와 셔틀 승객실 창은 `glazing_companions`의 짝을 함께 조립합니다. 완성본과 기본/대체 목록에는 포함되어 있습니다. 자세한 규칙은 [후속 자산 안내](REFINED_CITY_ko.md)를 따릅니다.

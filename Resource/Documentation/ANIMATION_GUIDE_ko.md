# 스켈레탈 애니메이션 연결 규격

이 문서는 리소스 사용을 위한 조합 정보입니다. 게임의 상태 머신·이동·조준·공격 코드를 구현하거나 수정하지 않습니다. 기계가 읽을 수 있는 전환 정보는 `animation_blending.json`, 실제 클립 길이와 이벤트는 `animation_clips.json`에 있습니다.

## 클립 구성 · 30fps

| 클립 | 프레임 범위 | 반복 | 용도 |
|---|---:|---|---|
| Reference_A | 0–1 | 아니오 | 모든 파트가 공유하는 바인드 기준 A 포즈 |
| Turn_Base | 0–1 | 아니오 | 회전 블렌딩 기준, root yaw=0. Reference_A와 같은 기준 자세 |
| Idle | 0–60 | 예 | 호흡·미세 움직임 |
| Walk | 0–30 | 예 | 제자리 걷기. 인체 좌우 교대, 4족 대각선 페어, 6족 교대 삼각 지지 |
| Run | 0–20 | 예 | 제자리 뛰기. Walk와 접지 위상을 공유 |
| Turn_Left_90 | 0–24 | 아니오 | 왼쪽 +90° 회전과 방향 전환 스텝 |
| Turn_Right_90 | 0–24 | 아니오 | 오른쪽 -90° 회전과 방향 전환 스텝 |
| Attack_Melee | 0–24 | 아니오 | 인체 타격 / 변이 생물 할퀴기·물기 / 기계 앞다리 타격 |
| Aim_Base | 0–1 | 아니오 | 인체 양손 코일 권총 조준 / 몹 방출기·포신 조준 기준 |
| Attack_Fire | 0–12 | 아니오 | 조준 자세에서의 사격·방출 반동. 시작과 끝은 Aim_Base |
| Jump_Start | 0–12 | 아니오 | 준비 자세 → 이륙 자세 |
| Jump_Air | 0–20 | 예 | 공중 체공. Start 끝과 Land 시작에 연결 |
| Jump_Land | 0–12 | 아니오 | 착지 충격 흡수 → 기본 자세 |
| Jump_Full | 0–36 | 아니오 | 수직 궤적을 골반/몸통에 구운 독립 점프 |
| Walk_To_Run | 0–24 | 아니오 | Walk 왼발 접지 → 가속 → Run 왼발 접지의 예제 전환 |

끝 프레임은 시작 프레임과 중복되는 루프 경계입니다. 반복 재생 시 0 ≤ t < duration로 샘플링하여 끝 포즈를 한 프레임 더 정지시키지 않습니다. 렌더된 접촉 시트의 마지막 칸은 이 경계를 확인하기 위한 것입니다. 회전·점프·타격은 반복하지 않습니다.

## 걷기 ↔ 뛰기

인체의 왼발, 4족의 0·3번 다리, 6족의 0·3·4번 다리가 **위상 0**에서 앞쪽 접지를 시작합니다. 반대 그룹은 **위상 0.5**입니다. 발의 위상 p를 0..1로 유지하고 Walk와 Run 모두 같은 p에서 샘플링한 뒤 위치는 선형 보간, 본 회전은 shortest-path slerp로 혼합합니다.

HUMAN_7H의 걷기는 각 발의 p=0..0.60 접지, p=0.60..1 회수이고, 뛰기는 p=0..0.40 접지, p=0.40..1 회수입니다. 걷기에는 양발 지지, 뛰기에는 짧은 양발 체공이 있습니다. 다른 생물의 기존 접지 0..0.5는 유지합니다. 부모 관절의 회전을 고려한 분석적 2본 IK를 일반 본 쿼터니언 키로 구웠습니다. 재생할 때 별도의 Blender IK 솔버를 필요로 하지 않습니다.

| 계열 | Walk 기준 속도 | Run 기준 속도 | 같은 위상으로 혼합할 속도 구간 |
|---|---:|---:|---|
| HUMAN_7H | 1.08 m/s | 2.46 m/s | 1.08–2.46 m/s |
| RiftGrazer | 0.72 m/s | 1.98 m/s | 0.72–1.98 m/s |
| VeilWalker | 0.72 m/s | 1.98 m/s | 0.72–1.98 m/s |
| RelaySentinel | 0.80 m/s | 2.10 m/s | 0.80–2.10 m/s |

혼합 가중치의 시작값은 `(speed-walk_speed)/(run_speed-walk_speed)`를 0..1로 제한합니다. 공통 위상 변화량은 시간 간격에 혼합된 주파수 `lerp(1.0, 1.5, weight)`를 곱합니다. 결과 속도는 걸음 길이와 주파수 모두에 영향을 받으므로 정확한 접지가 필요하면 리소스의 가중치별 접지 궤적 또는 게임 측 발 고정으로 보정합니다. 기준 속도는 평지 접지 궤적에서 계산한 값입니다. 문서의 월드 단위에서는 모두 0.5배입니다.

Idle→Walk는 0.18초, Walk↔Run은 위상을 유지하며 0.20초, 이동→Idle은 0.18초 교차 혼합을 시작값으로 사용합니다. 이 수치는 조율용 아트 정보이며 게임 동작을 강제하지 않습니다. 벽에 막혀 실제 이동 속도가 0이면 이동 루프도 정지/Idle로 전환합니다.

`Walk_To_Run`은 왼발 접지 시점에서 들어가는 0.8초짜리 실제 전환입니다. 내부 보행 위상은 `0.8*t+0.2*t*t`이므로 시작 주파수 1Hz와 끝 주파수 1.5Hz가 Walk·Run에 이어집니다. 시작은 Walk 위상0, 끝은 Run 위상0과 일치합니다. 중간 위상에서 속도가 바뀌면 이 고정 클립에 뛰어들기보다 위상 동기 혼합을 사용합니다. 감속 전용 Run_To_Walk 파일은 없으며 Walk↔Run 혼합을 사용합니다.

## 회전과 기본 포즈

`Turn_Base`는 root의 회전이 없는 기준 포즈입니다. 왼쪽/오른쪽 클립은 0.8초 동안 root 본의 yaw를 0→±90°로 바꿉니다. 회전 시작 시 현재 포즈에서 0.10초에 걸쳐 혼합하고 끝에서 Idle로 0.12초 혼합합니다. 작은 각도의 제자리 회전은 Turn_Base와 같은 시점의 Turn 클립을 `abs(angle)/90`으로 혼합할 수 있지만, 발 간격은 최종 각도에 맞춰 확인해야 합니다.

**root yaw를 두 번 적용하지 않습니다.** 권장 방식은 root의 프레임간 yaw를 Actor에 전달하고 스켈레톤에서는 추출한 yaw를 제거하는 것입니다. root를 리그에서 그대로 재생하는 방식이면 Actor에 같은 각도를 동시에 더하지 않습니다. 다음 클립으로 넘어갈 때 Actor 방향과 root 기준을 함께 재설정합니다. 90°보다 큰 방향 전환은 회전 클립을 이어 사용하거나 별도 회전 정책으로 처리합니다.

이동 중 방향 전환은 이동 위상을 유지한 채 Actor의 방위를 보간하고, 제자리 스텝 클립은 정지 상태에서 사용합니다. 서로 반대인 쿼터니언 표현 사이에서는 부호를 맞추고 최단 경로로 보간합니다.

## 이동 중 사격·공격

인체는 하체의 Walk/Run/Jump를 유지하면서 `spine, chest, neck, head, clavicle.L/R, upper_arm.L/R, forearm.L/R, hand.L/R, weapon_socket, back_socket, muzzle`에 Aim_Base/Attack_Fire를 **상체 override**로 적용할 수 있습니다. root·pelvis·다리는 마스크에서 제외합니다.

사격의 준비 자세는 Aim_Base입니다. Idle에서 Attack_Fire로 바로 들어가면 팔이 순간적으로 올라가므로 0.15초 조준 혼합을 먼저 합니다. Aim_Base→Attack_Fire는 0.03초, 반동 후 Aim_Base 복귀는 0.06초를 시작값으로 사용합니다. 연속 사격은 반동 클립을 재시작할 수 있습니다. 상체 오버라이드는 상대/가산 포즈가 아닙니다. 가산 반동이 필요하면 **Attack_Fire의 본별 변환에서 Aim_Base를 뺀 델타**를 만들어 적용해야 합니다.

몹의 사격 마스크는 head / jaw / weapon_socket / muzzle입니다. 걸음과 몸통 리듬은 이동 레이어에서 유지합니다. Attack_Melee는 몸통과 앞다리를 함께 쓰므로 기본은 전체 몸 클립이며, 공격 직전 이동을 감속합니다. 타격 프레임에 맞춘 판정만 게임에서 연결합니다.

발사/방출 시점은 Attack_Fire 위상0.08(약 1프레임), 근접 타격 창은 Attack_Melee 위상0.46–0.60입니다. GLB가 이벤트 콜백을 실행하는 것은 아니며, `animation_clips.json`의 이벤트를 읽어 게임에서 연결해야 합니다. 스켈레톤의 muzzle 본은 발사 위치·방향 참조점입니다.

## 점프

권장 조합은 `이동 → Jump_Start → Jump_Air(필요한 만큼 반복) → Jump_Land → 이동/Idle`입니다. Start 끝과 Air 시작, Air 끝과 Land 시작의 본 포즈를 맞췄으므로 경계는 0–0.03초만 혼합해도 됩니다. 착지 후 이동 복귀는 0.12초를 시작값으로 합니다. 점프 중 입력에 따른 수평 이동과 실제 높이는 게임의 이동 궤적에서 제어합니다. 공중 클립에도 발을 접는 소규모 시각적 몸통 높이 오프셋이 포함되어 있습니다.

`Jump_Full`은 다른 선택지입니다. 약 0.4–0.5m의 전체 시각적 높이 궤적이 pelvis/body에 들어 있습니다. 별도의 같은 높이 상승을 Actor에도 적용하면 높이가 중복됩니다. segmented 점프와 Full 점프를 동시에 적용하지 않습니다. 높은/낮은 지형과 충돌에 대응해야 하면 segmented 점프를 사용합니다.

## 파트 변경 시 유지할 정보

본 이름과 부모, 바인드 행렬, 원점, 키와 축을 유지합니다. 키/비율을 바꿀 때는 리그와 해당 파트를 함께 바꾸고 재타기팅해야 합니다. 외형 두께만 다른 같은 체형 파트는 공통 리그에 바로 대응됩니다. 의복은 체형과 같은 이름의 변형을 고르고 가려지는 신체 슬롯을 비웁니다. 무기 소켓과 muzzle 본은 이동·사격 중에도 유지합니다.

## 가동 건축

PressureDoor_Rig는 root와 leaf로 이루어진 2본 스킨입니다. Door_Open은 leaf를 +X로 1.25m 옮기고 Door_Close는 되돌립니다. 재생 시간은 각각 1초입니다. 문 옆 벽 안에 수납 공간을 두고, Open 종료 위치를 유지한 상태에서 Close를 시작합니다. 문 충돌의 개폐 판정 시점은 게임에서 결정합니다.

## 도시 반응 추가 납품

인체는 기존 43개 + 조준 이동 16개 + 권총 운반/재장전 4개의 총 63클립입니다. [상체 개선·8방향 걷기/달리기](AIM_LOCOMOTION_ko.md), [권총 운반·재장전 레이어](PISTOL_LAYERS_ko.md)를 참고합니다. 앞으로 제작 시 Mixamo 동작 미리보기를 기본 레퍼런스로 사용합니다. 인체 모션의 편집 타임라인은 30fps, GLB 샘플링은 60Hz이며 길이는 동일합니다. 방향별 피격·넘어짐·회복·사망, 도주, 제압 사격과 차량 충격은 `CIVIC_ANIMATION_GUIDE_ko.md`와 `civic_animation_contract.json`을 따릅니다. 게임용 합성 Ride는 별도이며, 새 Ride_Base를 자동 연결하지 않습니다. 기존 생물/문/비행체의 클립은 유지했습니다.

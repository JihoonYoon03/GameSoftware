# 3D 모델링 레퍼런스 도면 제작 지침

이 작업 공간에서는 모델링 에이전트가 사용할 콘셉트 아트와 치수 도면을 제작한다. 산출물은 2D 이미지이며, 실제 메시 제작은 모델링 에이전트가 담당한다.

## 제작 전에 확인할 자료

- [그래픽 리소스 요청과 제작 계약](../RENDER_RESOURCE_REQUEST.md) 1~3절과 7절에서 대상의 사용 목적, 제작·납품 상태, 조립 단위, 공유 재질, 적용할 폴리곤 예산을 확인한다. 해당 리소스의 기존 도면·메시·파츠 ID를 대조해 재사용할 파츠와 새로 그릴 파츠를 정한다.
- [폴리곤 예산표](POLYGON_BUDGET_ko.md)에서 대상의 버전과 종류를 확인한다. 기존 v3 유지분은 [파트별 예산 목록](part_polygon_budgets.json)도 확인한다.
- 인체와 직업별 외관은 [체형·의복·부착 파트 규격](CHARACTER_DESIGN_ko.md), [조립 레시피](assembly_recipes.json), [부착 소켓](accessory_sockets.json)에서 체형·파트 이름·부착 위치를 확인한다.

## 시트 구성

| 영역 | 표시할 내용 |
|---|---|
| **FRONT · 정면도** | 모델의 앞쪽을 수평으로 본 정투영. 전체 높이와 폭, 중심선, 좌우 파츠 배치를 표시한다. |
| **RIGHT SIDE · 우측면도** | 모델 자체의 오른쪽에서 수평으로 본 정투영. 정면도와 같은 높이에서 앞뒤 깊이와 돌출부를 확인할 수 있게 한다. |
| **TOP · 상면도** | 모델의 바로 위에서 수직으로 내려다본 정투영. 전방 방향을 표시하고 정면도의 폭과 우측면도의 깊이를 맞춘다. |
| **CONCEPT · 콘셉트 아트** | 최종 실루엣, 소재, 색, 사용감과 역할이 드러나는 이미지 1장. 사선 시점과 자연스러운 자세를 사용할 수 있다. 모델만 무채색 또는 흰 바탕에 두고 배경, 무관한 소품, 장식은 생략한다. |

첨부된 조종사·경비원·항구 주민·탐사원·의무병 예시처럼 착용 상태의 정면도와 우측면도를 나란히 두고, 상면도와 분리 파츠 도면을 한 영역에 모으며, 전체 콘셉트를 옆에 둔다. 체형 비교 시트는 `Male_Lean` / `Male_Normal` / `Male_Heavy`, `Female_Lean` / `Female_Normal` / `Female_Heavy` 예시처럼 모델별로 정면·우측면·상면도를 묶고 같은 축척과 지면선을 쓴다. 체형 비교 시트에도 콘셉트 영역 1개를 포함한다.

한 장에 여러 모델을 넣을 때는 모델마다 사각 구획을 두고 구획 상단에 **모델명 또는 파츠 ID**를 적는다. 배낭·헬멧·벨트·조끼·파우치처럼 독립 제작하는 의복이나 장비는 착용 예시와 별도로 각각의 구획에 정면·우측면·상면도를 넣는다. 시트 전체에 합본을 넣을 때는 조립 상태임을 표시한다. 작은 파츠는 확대할 수 있으며, 확대 구획 안의 세 뷰는 같은 축척으로 그리고 그 축척을 따로 표시한다.

## 정투영과 치수

- 세 뷰에 동일한 형상과 자세를 사용한다. 투시, 카메라 기울기, 가까운 쪽이 확대되는 표현을 제거한다. 인체 조립 도면은 해당 리그의 공통 바인드 포즈와 양발 사이 지면 원점을 사용한다.
- 정면과 우측면의 **높이**, 정면과 상면의 **폭**, 우측면과 상면의 **깊이**를 같은 기준점에서 맞춘다. 머리 꼭대기·어깨·골반·무릎·발바닥이나 조립면·구멍·가동축처럼 모델링에 쓰이는 기준선을 필요한 곳에 표시한다. 착용 상태와 분리 파츠의 실루엣 및 부착 위치도 대조한다.
- 실제 제작 치수는 미터 단위로 표기한다. 전체 폭·깊이·높이와 조립에 필요한 피벗, 소켓, 접촉면의 위치를 표시하고, 경계에 돌출부나 장비가 포함되는지 적는다. 기존 자산은 프로젝트 실측과 계약값을 사용한다. 새 자산에 확정값이 없으면 설계 치수임을 명시하고, 확인이 필요한 값은 `미확정`으로 표시한다.
- 콘셉트의 포즈나 음영으로 형상이 다르게 보일 때 모델링의 크기와 배치는 세 정투영 도면과 치수 표기를 기준으로 삼는다. 최종 제출 전 기준선과 주요 치수를 세 뷰에서 교차 확인한다.

## 아트 방향과 텍스처 표현

- **Star Citizen을 주 레퍼런스로 삼는다.** 실루엣, 장비 배치, 의복의 구조, 부품이 결합되는 방식은 Star Citizen 쪽에 더 큰 비중을 둔다. **Starfield는 보조 레퍼런스**로 두고 개척지 특유의 색감, 소재, 마모 표현에 활용한다.
- 미래적인 인상은 직업별 장비의 형태와 결합 구조에서 드러나게 한다. 조종사의 헬멧 잠금 링과 일체형 통신부, 정비공의 공구 도킹 레일, 의무병의 교체식 진단 모듈처럼 역할을 읽을 수 있는 구조를 우선한다. 직물과 성형 외장의 전환, 관절의 겹침 구조, 장비 체결부를 정투영에서도 알아볼 수 있게 그린다. 발광과 색상은 상태 표시나 조작부 식별에 활용한다.
- 정투영과 콘셉트 모두 최종 텍스처가 적용된 외관으로 그린다. 직물·고무·도장 금속·노출 금속·유리의 색과 반사 차이, 마모 위치, 재질 경계를 읽을 수 있게 한다. 밑색 참고는 방향성 조명·그림자·블룸 없이 제시한다.
- 텍스처 참고 영역을 넣는 경우 공유할 소재와 적용 파츠를 표시한다. 직물·고무·도장 표면처럼 반복하는 소재 견본은 상하·좌우 가장자리가 이어지는 심리스 형태로 제시한다. 로고·라벨·국소 마모는 해당 위치를 표시하고, 공통 모서리나 패널선은 개발 계획에 맞춰 공유 트림으로 지정한다.

## 파츠 조립과 폴리곤 상한 반영

- 도면에 재사용 파츠와 신규 파츠, 조립에 필요한 연결점, 좌우 구분, 재질 적용 구역을 표시한다. 교체 장비·가동부·부착부는 필요한 독립 파츠로 지정하고, 색상·오염 변형은 공유 재질로 표현할 수 있게 한다. 인체는 `HUMAN_7H`의 기존 공통 바인드 포즈를 따르고, 체형별 의복과 소켓을 맞춘다.
- **v3 유지분**은 R1·R2의 엔진 통합·검증 전까지 기존 파트별 상한을 적용한다. 최대 **200삼각형**이며, 개별 파트의 정확한 상한은 예산 목록을 따른다.
- **신규 및 CQ-11 리메이크 v4 자산**은 경계 상자 대각선 길이 기준의 독립 파츠 LOD0 상한 **400 / 800 / 1,500 / 3,000 / 5,000삼각형**과 종류별 완성 조립체 상한을 함께 적용한다. 예를 들어 일반 NPC는 **12,000**, 플레이어·주연은 **18,000삼각형**이다. 대상별 LOD와 그림자 프록시 요구는 예산표를 확인한다.
- 실루엣을 바꾸는 곡면, 실제 작동부, 접속면은 형상으로 표시한다. 작은 볼트·봉제선·얕은 홈 등은 공유 Normal/ORM/Trim으로 표현할 표면 디테일로 구분한다. 상한에 맞추기 위한 임의 파츠 분할과 추가 GLB 생성을 전제로 도면을 설계하지 않는다.

## 제출 전 확인

- 정면·우측면·상면이 같은 축척과 형상을 공유하고 폭·깊이·높이 및 연결점이 일치한다.
- 조립 상태와 분리 파츠의 관계를 확인할 수 있고, 여러 모델이 들어간 경우 각 사각 구획에 이름이 있다.
- 콘셉트 1장에 대상 모델의 최종 외관이 드러나며 장식과 배경이 생략되어 있다. 정투영에서도 직업의 용도와 미래적인 인상을 형상과 장비 배치로 확인할 수 있다.
- 도면에서 재질 경계, 재사용 파츠, 필요한 연결점, 적용할 폴리곤 예산을 확인할 수 있다.

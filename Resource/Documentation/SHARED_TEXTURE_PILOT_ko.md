# 공유 텍스처 시범 세트

2026-11-23. 그래픽 요청서의 GFX-01과 GFX-03에 따라 정비소, 45도 곡선 도로·보도, 쿠페, 리아의 작업복, 광산 지지대·등에 공유 재질을 적용했습니다. Blender에서 5개 장면을 열 수 있고, 원본과 시범 적용 결과를 같은 카메라·조명에서 비교할 수 있습니다. [Blender 원본](../Source/Shared_Texture_Pilot.blend) · [전후 비교](../Preview/TexturePilot/comparison.jpg) · [제작 요청서](../RENDER_RESOURCE_REQUEST.md)

| 공유 표면 | 시범 적용 |
|---|---|
| 도장 금속 | 쿠페의 청록색 외장. 중립색 표면에 원래 선형 색을 곱합니다. |
| 브러시 금속 | 쿠페, 정비소, 리아의 금속 장비, 광산 지지대에 공용으로 적용합니다. |
| 기술 직물 | 리아의 황토색과 남색 의복에 같은 직조 맵을 씁니다. |
| 주물 포장 | 곡선 보도와 연석에 같은 맵을 배정하고 원래 재질색으로 구분합니다. |
| 기존 512 타일 | 노면의 현무암, 정비소의 외장과 콘크리트, 광산 암석을 재사용합니다. |
| 피부·유리·발광 | 기존 피부색, 유리의 알파 상태와 발광 상수를 사용합니다. |

새 표면은 1024×1024 무손실 PNG 4세트입니다. 세트마다 BaseColor, +Y 탄젠트 공간 Normal, ORM을 한 장씩 제공합니다. 표면은 반복 타일이며 기존 `TEXCOORD_0`와 `TANGENT.w`를 사용합니다. 금속·포장·노면 파트의 텍셀 밀도 중앙값은 약 108~128 texel/m이고 직물 파트는 약 234~256 texel/m입니다. 각 맵의 색 공간·채널, 재질별 UV 배율, 파트별 밀도와 콘텐츠 해시를 기록했습니다. [공유 재질 및 프리팹 명세](shared_texture_pilot.json) · [신규 PNG](../Export/Textures/Pilot)

시범에 참조한 맵은 24개이며, 내용과 색 공간으로 중복을 제거하면 23개입니다. 전체를 비압축 RGBA8로 올리고 모든 밉을 할당할 때의 추정치는 약 **78.7 MiB**입니다. 검토 장면의 불투명 재질 ID는 정비소 7개, 곡선 도로·보도 5개, 쿠페 5개, 리아 17개, 광산 2개입니다. 발광과 반투명 재질은 별도로 집계했습니다. 광산을 제외한 장면은 시범 슬롯 목표를 넘으며, 사용 중인 재질 구분을 보면서 결합 후보를 판단할 수 있도록 비용을 기록했습니다. 이 수치는 재질 ID 개수이며 실제 드로우 수는 통합 단계에서 측정합니다.

참조 GLB 9개에서 모듈과 파트 ID, 삼각형 예산, UV, 탄젠트, 가동·부착 범위를 대조했습니다. 맵을 사용하는 슬롯에서 퇴화 UV나 잘못된 탄젠트가 발견되지 않았습니다. Blender 원본을 다시 열어 5개 장면의 파트별 삼각형 수, 이미지 색 공간, 리아의 23본을 확인했습니다. 곡선 도로의 노면·페인트·보도·연석은 각각의 원래 파일과 접속 계약을 참조합니다. [Blender 재열기 검사](../Validation/texture_pilot_blender.json)

현재 범위는 Blender 시범과 선별 GLB의 준비 상태 점검입니다. 실제 인게임 밉·그림자·성능 검수와 GLSL 렌더 경로 연결은 게임 통합 단계의 작업입니다. 실측 건물(GFX-02)과 나머지 자산군에는 시범 검수 결과를 적용합니다.

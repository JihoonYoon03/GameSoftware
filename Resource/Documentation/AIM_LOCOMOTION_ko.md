# 상체 개선과 조준 상태의 방향별 이동 — 2026-10-27

기존 인체 43클립을 유지·개선하고, **조준 걷기 8방향 + 조준 달리기 8방향**을 추가했습니다. 총 59클립이며 기존 HUMAN_7H 23본과 부품 원점·스킨을 사용합니다. 캐릭터 10종의 조립 GLB와 Blender 원본에 반영합니다.

## 상체 변경

걷기·달리기의 팔꿈치를 몸 옆의 시상면에서 굽히고, 손의 궤적이 가슴의 움직임을 따라가도록 했습니다. 옆으로 과하게 벌어진 어깨와 팔꿈치를 줄이며 반대쪽 다리와 팔의 타이밍을 유지합니다. 이전에 개선한 하체 보행 궤적은 유지합니다.

조준 자세는 팔꿈치를 손목 아래에 두고 몸 가까이 내렸습니다. 양손 목표를 같은 무기 변환에서 계산하되, 실제 팔 길이 안에 두어 왼손이 도달하지 못하는 문제를 줄였습니다. 피격·반동도 이 공통 그립을 사용합니다.

Mixamo의 공개 3D 미리보기에서 `Walking`(Walking While Aiming Rifle), `Walking Backwards`(Walking Backwards While Aiming Rifle), `Pistol Strafe`(Strafe Left With An Aimed Pistol), `Unarmed Run Forward`를 재생해 참고했습니다. 조준 중 어깨·시선의 안정성, 팔꿈치 방향, 다리를 교차하지 않는 옆걸음, 팔과 다리의 반대 위상을 참고해 기존 리그에 직접 키를 제작했습니다. Mixamo 파일을 내려받아 자동 리타기팅한 결과는 아닙니다.

## 새 클립

아래 방향마다 `Aim_Walk_방향`과 `Aim_Run_방향`을 제공합니다. 모든 클립의 몸은 조준 방향인 **-Y**를 계속 바라보며, 옆걸음 클립 전체를 회전시켜 다른 방향을 대신하지 않습니다.

| 이름 끝부분 | 이동 방향 | 걷기 속도 | 달리기 속도 |
|---|---|---:|---:|
| Forward | 전진 | 0.90m/s | 1.80m/s |
| ForwardLeft | 전방 왼쪽 | 0.75m/s | 1.50m/s |
| Left | 왼쪽 | 0.65m/s | 1.25m/s |
| BackLeft | 후방 왼쪽 | 0.65m/s | 1.20m/s |
| Back | 후진 | 0.65m/s | 1.20m/s |
| BackRight | 후방 오른쪽 | 0.65m/s | 1.20m/s |
| Right | 오른쪽 | 0.65m/s | 1.25m/s |
| ForwardRight | 전방 오른쪽 | 0.75m/s | 1.50m/s |

걷기는 1초, 달리기는 2/3초 루프입니다. 편집 타임라인은 30fps, GLB 표본은 60Hz입니다. 위상 0은 왼발 접지, 0.5는 오른발 접지이며 방향을 바꿔도 같은 위상을 사용합니다. 옆걸음·대각선은 발 간격을 확보해 다리 교차를 피합니다. 후진과 스트레이프는 몸을 돌려 도망가는 `Flee_Run`과 구분합니다.

## 360도 블렌딩 연결

[aim_locomotion_blending.json](aim_locomotion_blending.json)에 정지 기준 `Aim_Base`, 16개 속도 표본, 24개 블렌딩 삼각형을 제공합니다. 좌표는 **X 양수=캐릭터 왼쪽**, **Y 양수=캐릭터 전방**인 속도 평면입니다. 원래 모델 좌표의 전방은 -Y이므로 입력 속도를 조준 방향의 캐릭터 좌표로 변환한 뒤 두 번째 성분의 부호를 바꿉니다.

입력 속도가 속한 삼각형의 무게중심 좌표를 가중치로 사용하고, 참여하는 클립을 같은 정규화 위상에서 평가합니다. 회전은 부호를 맞춘 쿼터니언 보간을 사용합니다. 방향·속도가 바뀌어도 위상을 다시 0으로 시작하지 않습니다. ±180도 경계도 같은 원형 연결을 사용합니다. 멈추면 마지막 이동 위상을 보관하고 `Aim_Base`로 부드럽게 전환합니다.

클립의 루트 이동과 루트 yaw는 0입니다. 실제 위치·충돌·조준 방향 회전은 게임에서 처리합니다. 이 납품에는 게임 코드·Runtime 등록을 포함하지 않습니다. 경사·계단 적응은 게임의 접지 처리와 결합할 수 있습니다.

개별 클립은 접지 검사를 통과하지만 관절 회전을 섞으면 발이 조금 낮아질 수 있습니다. 인접 방향 384개 표본에서 최대 약 11mm가 관찰됐습니다. 연결 데이터의 `blend_floor_correction`에 발바닥 기준점과 보정식을 기록했습니다. 블렌딩 뒤 최저 발바닥이 지면보다 낮으면 그 차이만큼 골반의 로컬 높이를 올려 1mm 여유를 둡니다. 이 보정은 배우 루트·충돌 위치를 바꾸지 않습니다. 경사면에는 발 접지 처리를 함께 사용하십시오.

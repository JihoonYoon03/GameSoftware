# 격리 구역 NPC 테스트

## 범위

`Concept.md`의 인물 성격과 안전·기록 우선 원칙을 현재 격리 구역에 시험 적용한다.
문서에는 20명의 구체적인 AI 패턴표가 없으므로 리아·카인·마라 외 인물은 테스트용으로 추가했다.
메인 스토리 1~3장, 퀘스트 플래그, 저장·로드 구현을 대체하지 않는다.
NPC는 사망하지 않으며 코스믹 호러 현상 자체를 처치 가능한 적으로 만들지 않는다.
적은 기존 고장 드론을 사용한다.

## 규모와 조작

- 기존 도시 관문의 E 진입 경로 유지. 격리 구역 64×64(기존 32×32의 면적 4배).
- 연결된 방 80개와 중앙 집결지. NPC 20명, 적 정원 72기, 처치 후 기존 12초 재출현.
- 집결지 반경 7에서는 적의 플레이어 추적·공격을 중지한다. 생성·재출현은 반경 8 밖.
- E 우선순위: 가까운 드롭 획득 → 귀환 관문 → 가장 가까운 NPC(1.7칸, 벽 너머 불가).
- 리아·카인 E: 대화와 시험 동행 토글. 다른 NPC도 가까이에서 E로 대화한다.
- 의무 인력 E: 체력 35 회복, 인물별 20초 대기. 상인 E: 부품 3개를 키트 1개로 교환.
- 캐릭터 옷 색은 역할별 구분, 가까이서는 이름·상태·성격 표시. 미니맵 노랑은 NPC.

## 인물과 패턴

| 인물 | 성격 | 행동 |
|---|---|---|
| 리아 | 실증적 | 설비 주변 조사·대기, E 시험 동행 |
| 카인 | 신중함 | 귀환로 순찰, 위험 시 후퇴, E 시험 동행 |
| 마라 | 낙관적 | 전력 점검을 표현하는 근거리 이동·대기 |
| 윤서 | 침착함 | 집결지 근거리 이동, 치료 |
| 도윤 | 꼼꼼함 | 집결지와 보급 지점 왕복 |
| 세라 | 호기심 | 외곽 측량 이동·기록 대사 |
| 준 | 소심함 | 집결지 주변 산책, 위험 회피 |
| 하린 | 실용적 | 고정 거래, 부품 교환 |
| 이안 | 원칙적 | 주변 순찰 |
| 나디아 | 양심적 | 기술 점검, 관측국 가동 반대 대사 |
| 오웬 | 회의적 | 관측 이동, 발신자 단정 금지 대사 |
| 민 | 성실함 | 보급 왕복 |
| 유리 | 다정함 | 집결지 근거리 이동, 치료 |
| 태오 | 과묵함 | 설비 주변 점검 |
| 로아 | 대담함 | 외곽 탐사, 위험 시 철수 |
| 에단 | 책임감 | 귀환로 순찰 |
| 소미 | 수다스러움 | 주민 산책, 구매 기록 불일치 대사 |
| 베크 | 신중함 | 고정 거래, 출처 기록 대사 |
| 레나 | 협동적 | 보급 왕복, 운반 지원 대사 |
| 시온 | 불안함 | 관측 이동, 선행 응답 대사 |

일상 이동은 역할별 거리와 개인별 대기 주기로 구분한다. 전 NPC가 시야 내 4칸의 적을
발견하면 자기 집결 위치로 후퇴한다. 동행도 위험 회피가 우선이며 안전해지면 재개한다.
격자 BFS 경로로 벽을 우회하며 NPC끼리/플레이어와는 충돌하지 않는다.
조사·정비는 현재 이동/작업 대기/대사 표현이며 실제 설비 수리 퀘스트는 별도 구현 대상이다.
동행·치료 대기 상태는 도시 왕복 시 같은 실행에서 유지되지만 프로그램 종료 시 저장되지 않는다.

## 사용자 확인 절차 (빌드·실행 미수행)

1. 재빌드 후 격리 구역 진입: HUD에 64×64, 주민 20, 적 정원 72 확인.
2. 중앙 바닥과 NPC 표시, 주변 NPC 이름·성격, 미니맵 표식과 실제 위치 일치 확인.
3. 리아·카인 E로 동행 시작/종료, 벽 우회, 적 접근 시 후퇴 후 재개 확인.
4. 주민·경비·운송·관측 인력의 이동 거리와 대기 차이 관찰.
5. 부상 후 의무 인력 치료, 재치료 대기, 부품 3개 이상/미만 상인 교환 확인.
6. 중앙에서 적 피해 없음, 외곽 공격·경험치·드롭·12초 재출현 확인.
7. 도시 왕복, 초기화 후 재진입, 여러 랜덤 맵에서 이동 가능한 지형 연결 확인.
8. 로그의 npc_update/npc_navigation 및 npc_path_visited_cells, FPS, draw call 확인.

추가 파일: LevelOneNpc.h/.cpp(상태·행동·대화), LevelOneNpcRenderer.cpp(화면 표현).
NPC 배치는 기존 Actor/SceneGraph 경로를 사용한다.
